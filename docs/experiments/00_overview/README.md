# 전체 실험의 목표와 판정

최종목표는음악의원래잔향을포함한4stem을분리하면서추가잔향없는음악과vocals를보호하는것이다. dry는추가합성RIR가없다는뜻이며무향녹음이라는뜻이아니다. B는HTD+BS-RoFormer50:50으로고정한다.

내부방법효과와최종일반화/실사용적격을구분한다. 최근G0는B대비wet+1.460dB의유망한내부결과지만개별dry2곡손상·음원합불일치가남아최종채택은보류다. 초기eval40앙상블+1.652dB는HTD대비/다른30초조건이므로누적하지않는다.

현재val10은반복설계·후보선택에노출됐고confirmation10도공개backbone개발데이터와중복된다. 기존CI는이연구전체의선택낙관성을보정한외부test CI가아니다. 정확무음/저에너지음원을결과를보고제외해기존판정을바꾸지않는다.
