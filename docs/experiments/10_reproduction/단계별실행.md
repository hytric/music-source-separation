# 격리 workspace의 단계별 실행

공통환경·full bundle검증·hydrate를마친뒤실행한다. 아래는기존논문값을만드는마법의명령이아니라**코드/설정/데이터를그대로새실험으로실행하는순서**다. 데이터노출·새GPU비결정성·학습확률성을해결했다는뜻은아니다. 예시는저장소루트에서실행한다.

```bash
WORK=/data/mss-run
```

## 초기30초 후보 비교와 eval40

```bash
python tools/reproduce.py stage --workspace "$WORK" --name baseline21
```

hydrate의test50원자료·실제16RIR·모델registry를사용한다. `config21.json`은원래개발CSV의10개모델대체/앙상블설정을복원해기본후처리11개와함께등록한다. validate→lock-policy→build-wet→develop→seal→evaluate를순차실행한다. candidate선택이원래와달라지면그것이실제재현결과이며원래앙상블로강제하지않는다. 외부기기의새성공이나clean-winner주장과구분한다.

## 소형 refiner와 공통cache

```bash
python tools/reproduce.py stage --workspace "$WORK" --name cache-refiner
python tools/reproduce.py stage --workspace "$WORK" --name preflight-refiner
python tools/reproduce.py stage --workspace "$WORK" --name train-refiner --allow-optimizer
```

cache-refiner는400조건의30초GT/HTD cache를새로생성한다. fixedRIR배열을사용하므로새gpuRIR시뮬레이션은하지않는다. 준비preflight의optimizer0과이후실제학습step을구분한다. 학습은3000회 pilot설정이며확인평가는자동으로실행하지않는다. 기존best2500효과는별도예측값이지새학습성공을미리규정하는값이아니다.

## 190초 magnitude/phase/EQ 원인 대조

```bash
python tools/reproduce.py stage --workspace "$WORK" --name cause-eq
```

원본code의pilot→all을실행한다. 입력190.22초/중앙30초/DSP760.87초를유지한다. core/test dev10과apply/internal val10이서로다르다. 40초예측을padding해대체하지않고oracle known-RIR EQ를blind방법의성과로보고하지않는다. 이단계는추론·FFT메모리/디스크비용이크다.

## 전처리 → 공식모델 → 미세조정 → 결합/선택/합보정

먼저위cache-refiner가완료돼야한다. WPE는원래별도vendor설치정책을유지한다.

```bash
python -m pip install --no-deps --target "$WORK/runtimes/frontend-verify-v1/vendor" \
  nara_wpe==0.0.11 click==8.5.1
python tools/reproduce.py stage --workspace "$WORK" --name frontend
python tools/reproduce.py stage --workspace "$WORK" --name official
python tools/reproduce.py stage --workspace "$WORK" --name finetune --allow-optimizer
python tools/reproduce.py stage --workspace "$WORK" --name hybrid
python tools/reproduce.py stage --workspace "$WORK" --name selector
python tools/reproduce.py stage --workspace "$WORK" --name consistency
```

각단계는앞단계의새binding/파일을사용하며새runtime은canonical이름으로구성한다. 공식모델비교는prepare/clean/rev/bsr/score를순차실행한다. 모든코드는workspace/code의복사본에서실행돼원래Git결과는유지된다. full신규학습은이번문서검증에서재실행하지않았다. dry/wet20조건을재사용하는후속설계이므로이명령을실행했다고새곡일반화가확인되는것도아니다.

## 재현 범위 밖인 것

초기OpenAIR제공숫자는원코드/원자료미확인으로재추론을보증할수없다. 초기잔향영향/성분대조의보고서·CSV는보존됐지만그당시단독실행스크립트는현재배포모듈에서완전하게확인되지않아새GPU재추론원클릭지원이라고표현하지않는다. 그프로토콜과원자료/RIR은포함돼있으며새로구현하면원래실험의독립재구현으로표시한다.

QG1teacher는별도portable teacher명령으로재생성가능하지만C/Q품질라벨학습전체CLI는아직미완료다. 실제mono/stereo실녹음·새외부평가·정식청감은실행결과가없으므로재현성공을만들어낼수없다.
