# 공식 PaRIRset SCNet 로컬 검증

2026-11-13

20조건·신규 CUDA 추론60회·320개 음원별 지표를 완료했다. wet에서 rev−clean은 +4.397 dB [+2.475, +9.137], rev−HTDemucs는 +3.198 dB [+1.651, +4.707], rev−50:50 앙상블은 +0.862 dB [-0.187, +1.731]였다. dry의 rev−clean은 -1.396 dB [-1.938, -0.968]다. 공식 rev 모델의 clean 대비 잔향 조건 개선은 사전 기준을 통과했다. 기존 앙상블 대비 확실한 우위도 확인하지 못했다. dry 손상도 관찰돼 무조건 교체는 권하지 않는다. wet의 vocals도 기존 앙상블 대비 −0.917 dB [−1.565, −0.141]로 악화됐다.

10 validation곡의 dry/wet, 40초 입력·중앙30초, 원래 잔향 정답을 유지했다. 공개 가중치의 RIR 학습 효과와 기존 기준선 대비 개선을 구분했다. 새 학습이나 confirmation 사용은 없고, 공개 모델이 이 validation곡을 사전 학습했을 수 있어 독립 일반화 결과로 해석하지 않는다.

공식 guso_ismir26 commit600585bc의 코드·clean/rev 가중치를 가져와 실행했고, 기존 전처리 실험의 입력 합성·HTDemucs 캐시만 재검증해 사용했다. 이 문서는 논문 표의 noisy-reverb SDR가 아닌 우리 R4 pure-reverb SI-SDR 결과를 추가한다.
