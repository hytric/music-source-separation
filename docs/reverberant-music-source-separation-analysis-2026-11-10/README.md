## 2026-11-14 결합·입력 선택 후속 검증

고정 결합은 B 대비 wet 전체 +1.577 dB [+0.725, +2.079], dry 전체 -1.253 dB [-1.424, -0.846]로 dry 보호 기준을 실패했다. vocals/other 파형은 B와 정확히 같고 새 bass 소실은 없다. 음원합의 상대잔차RMS 중앙값은 dry에서 B 0.0230→H 0.0922, wet에서 0.0545→0.1919로 커졌다.

train80곡320입력만으로적합한실제입력선택기는B 대비 wet 전체 +1.460 dB [+0.080, +2.062], dry 전체 +0.000 dB [-0.155, +0.000]였다. 사전 기준은 통과했다. dry에서B/H=8/2, wet에서B/H=2/8를선택했다. 검증곡정답/조건라벨은선택에사용하지않았다. 다만 dry 2곡을 잘못 선택해 St Vitus −0.310dB, Titanium −2.202dB 손상이 남았다. dry 중앙값0을 모든 곡의 무손상으로 해석하지 않는다.

## 2026-11-13 분리기 추가 학습

공식 rev 분리기를 train80곡의 dry/wet 대응 쌍으로 실제1,000회 갱신하고500/1,000회에서 각각20조건을 평가했다. 선택 step1000의 초기 rev 대비 wet 전체는 +0.509 dB [+0.286, +0.902], dry 전체는 +0.182 dB [+0.057, +0.239], wet vocals는 +0.097 dB [+0.063, +0.536]다. 기존 앙상블 대비 wet 전체는 +1.531 dB [+0.173, +2.243]였다. 사전 개선·보호 기준은 모두 통과했다. 기존 앙상블 대비 dry 전체는 -2.154 dB [-2.561, -1.777], wet vocals는 -0.403 dB [-1.135, +0.074]로 격차가 남아 전 입력 교체는 권하지 않는다.

## 2026-11-13 추가 검증

20조건·신규 CUDA 추론60회·320개 음원별 지표를 완료했다. wet에서 rev−clean은 +4.397 dB [+2.475, +9.137], rev−HTDemucs는 +3.198 dB [+1.651, +4.707], rev−50:50 앙상블은 +0.862 dB [-0.187, +1.731]였다. dry의 rev−clean은 -1.396 dB [-1.938, -0.968]다. 공식 rev 모델의 clean 대비 잔향 조건 개선은 사전 기준을 통과했다. 기존 앙상블 대비 확실한 우위도 확인하지 못했다. dry 손상도 관찰돼 무조건 교체는 권하지 않는다. wet의 vocals도 기존 앙상블 대비 −0.917 dB [−1.565, −0.141]로 악화됐다.

[09 공식 SCNet 검증](09_공식SCNet_검증_2026-11-13.md)에서 조건·수치·한계를 확인한다. 기존11월10일 test40 결과와 합산하지 않는다.

GitHub에서는 아래 Markdown 문서와 CSV·그림을 읽는다. HTML을 한 번에 읽으려면 저장소를 내려받아 같은 폴더의 [공유본.html](공유본.html)을 브라우저로 연다. GitHub의 HTML 파일 화면은 소스를 표시한다. 이 폴더에는 보고서·설정·집계표·그림만 포함하며 원 음원·모델·실행 cache는 포함하지 않는다.

**프로젝트는 잔향 조건 생성과 오류 분석을 넘어, 두 모델을 결합하는 방법의 평가까지 진행됐다.** 2026년 11월 10일 21:35 KST에 완료된 실행 기록과 결과를 확인했다. HTDemucs와 BS-RoFormer의 출력을 같은 비율로 평균한 방법은 평가 40곡에서 기준 HTDemucs 대비 **SI-SDR +1.652 dB**, 곡 단위 재표집 95% 신뢰구간 **[+1.518, +2.000] dB**를 보였다. 베이스 소실 조건은 **31/160 → 12/160**으로 감소했다.

다만 이것은 **고정된 합성 잔향 조건에서 모델 결합의 효과**다. RT60 적응형 후처리, 새로운 분리 알고리즘, 실제 공연장 일반화 또는 청취 선호도 향상이 입증된 것은 아니다. 평가 40곡에는 과거 오류 분석에서 확인한 이력이 있으므로 완전히 새 자료에 대한 검증으로 표현하지 않는다.

이후 추가 실험도 완료했다. [07 추가 잔향 영향 분석](07_추가잔향_영향분석.md)은 HTDemucs로 추가 잔향 없는 50곡을 분리해 기존 잔향 200조건과 비교한 결과다. R4에서 원본 대비 베이스 SI-SDR 변화량 중앙값은 −14.51 dB였고, 베이스 소실은 원본 0/50곡에서 잔향 41/200조건으로 늘었다. [08 잔향 성분 대조](08_잔향성분_대조결과.md)는 개발 10곡의 지연·초기 반사·전체 잔향 비교다. 베이스의 대응 차이는 지연만−원본 +0.020 dB, 초기 R4−지연 −4.326 dB, 전체 R4−초기 −6.399 dB였다. 이는 원인 진단이며 새로운 후처리 성능 개선 결과는 아니다.

남은 과제는 **두 모델 결합 이득의 추가 잔향 유무 비교, 자체 보정 방법의 검증, 청취 평가와 독립된 새 곡·새 RIR 평가**다. 05 문서는 추가 실험 전의 계획이며, 07 문서에서 예정했던 성분 대조는 08에서 완료됐다. 세부 실험 설정과 수치의 근거는 각 보고서에 보존했다.
