# SCNet dry·wet 혼합 미세조정

2026-11-13

공식 rev 분리기를 train80곡의 dry/wet 대응 쌍으로 실제1,000회 갱신하고500/1,000회에서 각각20조건을 평가했다. 선택 step1000의 초기 rev 대비 wet 전체는 +0.509 dB [+0.286, +0.902], dry 전체는 +0.182 dB [+0.057, +0.239], wet vocals는 +0.097 dB [+0.063, +0.536]다. 기존 앙상블 대비 wet 전체는 +1.531 dB [+0.173, +2.243]였다. 사전 개선·보호 기준은 모두 통과했다. 기존 앙상블 대비 dry 전체는 -2.154 dB [-2.561, -1.777], wet vocals는 -0.403 dB [-1.135, +0.074]로 격차가 남아 전 입력 교체는 권하지 않는다.

기존 공식 모델 비교는 공개 가중치의 추론만 실행한 실험이고, 이번에는 분리기 전체10,578,768개 파라미터에 AdamW 갱신을 수행했다. 초기 출력과 기존 rev cache의 차이는0이고, 학습 체크포인트의 strict 재적재/가중치 변화/optimizer step 일치를 확인했다. train RIR만 사용하고 validation/confirmation 음원을 추가 최적화에 넣지 않았다.

평가는 이전과 같은40초 입력·중앙30초·원래 wet 정답이다. vocals 손상이 전체 개선에 가려지지 않도록 별도 비열등성 기준을 적용했다. checkpoint 선택은 validation에 의존하고 공개 모델 사전 학습과 중복될 수 있으므로 독립 일반화 검증은 아니다. confirmation과 청감 평가는 이번에 수행하지 않았다.
