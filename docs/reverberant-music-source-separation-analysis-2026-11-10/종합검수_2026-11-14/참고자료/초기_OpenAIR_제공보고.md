# 잔향 환경 음원 분리 후처리: 지금까지의 시험과 다음 후보

Separation 팀 (이승헌, 이수아) · 2026-11-08

후처리의 입력과 출력을 먼저 정의하고, 지금까지 시험한 방법과 결과, 다음에 시험할 후보를 같은 형식으로 정리했습니다.

## 1. 실험 설정 요약

| 항목 | 내용 |
|---|---|
| 데이터 | MUSDB18-HQ test 50곡의 30초 구간 (개발용 10곡, 평가용 40곡, 곡 단위 분리) |
| 잔향 | OpenAIR 실측 RIR, 4개 공간 (R1~R4, RT60 0.26 / 0.89 / 1.28 / 1.96 s) |
| 잔향 적용 | 같은 공간에서 악기마다 다른 위치의 RIR(B-format W 채널, mono)을 stem의 좌우 채널에 같게 convolution |
| 음량 | 잔향 stem의 RMS를 같은 곡의 원본 stem RMS에 맞춤 (조건 간 악기 균형 동일) |
| 분리 모델 | 사전학습 HTDemucs (`htdemucs`, 4-source), 비교용 MDX-Net (2-source) |
| 정답 | 같은 조건의 **잔향이 적용된 stem** (잔향 제거가 아니라 잔향 상태에서의 분리 품질 평가) |
| 형식 | 44.1 kHz, stereo, 30초 (1,323,000 샘플) |

MUSDB stem 자체의 좌우 패닝은 남아 있지만, 잔향으로 인한 좌우 차이는 없습니다(좌우에 같은 RIR 적용).

## 2. 후처리의 입력과 출력

후처리 대상은 HTDemucs 4-source 분리 결과입니다.

| 구분 | 기호 | 내용 | 형태 | 파일 |
|---|---|---|---|---|
| 입력 1 | `x` | 잔향 혼합 음원 | (2, N) | `reverb_data/<split>/<곡>/<조건>/mixture.wav` |
| 입력 2 | `ŝ_i`, i ∈ {vocals, drums, bass, other} | HTDemucs 분리 결과 | 4 × (2, N) | `separation_data/htdemucs/<split>/<곡>/<조건>/<음원>.wav` |
| 입력 3 (선택) | `T60` | 공간의 잔향 시간 (4개 위치 RIR의 T30 평균) | 숫자 1개 | `dataset/manifest.csv`의 `rt60_s` |
| 출력 | `y_i` | 보정된 음원 | 4 × (2, N), 입력과 같은 길이 | 새 결과 폴더 |
| 평가에만 사용 | `s_i` | 잔향이 적용된 정답 stem | 4 × (2, N) | `reverb_data/.../<음원>.wav` |

**규칙**
- 정답 `s_i`는 후처리에 쓰지 않습니다. 설정값은 개발용 10곡에서만 고르고, 평가용 40곡에는 고정된 설정으로 한 번만 적용합니다.
- 실제 공간에서는 RIR을 모르므로, RIR 자체는 입력으로 쓰지 않습니다. `T60`도 실제로는 추정이 필요하며, 지금은 측정값을 그대로 씁니다.
- 출력의 합이 혼합 음원과 같은지(`Σ y_i = x`)는 방법마다 표시합니다.

**STFT 설정 (시험 공통)**: `scipy.signal.stft`, periodic Hann 창, 창 길이 4096, hop 1024, 채널별로 독립 처리. 마스크 방식은 혼합 음원의 위상을 그대로 사용합니다.

## 3. 평가 방법 (시험)

| 항목 | 내용 |
|---|---|
| 데이터 | 개발용 10곡 × 잔향 4조건 = 40개 샘플 (잔향 없는 조건 제외) |
| 지표 | SI-SDR, SI-SIR, SI-SAR (Le Roux et al., 2019). 좌우 채널을 이어 붙인 신호로 계산하고, SI-SIR/SI-SAR은 정답 4개가 이루는 공간으로 투영해 나눔 |
| 집계 | 후처리 후 − 후처리 전 변화량을 샘플마다 4개 음원 평균 → 40개 샘플의 중앙값 |
| 개선 비율 | (샘플, 음원) 160쌍 중 SI-SDR이 올라간 비율 |
| 하지 않은 것 | BSS Eval SDR, 청취 평가, 처리 시간 측정 |

후처리 전 HTDemucs 성능 (개발용, 잔향 4조건, 샘플 중앙값 SI-SDR): vocals 5.93, drums 4.11, bass 1.40, other 1.71 dB.

## 4. 지금까지 시험한 방법

### 4.1 방법 정의

모든 마스크 방법의 출력은 `y_i = ISTFT(M_i ⊙ X)`이고, `X = STFT(x)`, `P_i = |STFT(ŝ_i)|²`입니다.

| ID | 방법 | 식 | 시험한 설정 | `Σ y_i = x` |
|---|---|---|---|---|
| T1 | Mixture Consistency | `e = x − Σ ŝ_j`, `y_i = ŝ_i + w_i e` | `w_i = 1/4` (균등), `w_i = ‖ŝ_i‖² / Σ‖ŝ_j‖²` (에너지 비례, 곡 전체 기준) | 예 |
| T2 | 비율 마스크 | `M_i = P_i^(α/2) / Σ_j P_j^(α/2)` | `α` = 1, 2, 4 | 예 |
| T3 | STFT 크기 변경 | T2와 같음, `α` = 2 | 창 길이 1024, 2048, 4096, 8192 (hop = 창 길이/4) | 예 |
| T4 | 잔향 꼬리 마스크 (RT60 사용) | `R_i[t] = a·R_i[t−1] + a(1−a)·P_i[t−1]`, `a = exp(−13.8155·H / (fs·T60))`, `Q_i = P_i + β R_i`, T2의 `P_i` 대신 `Q_i`, `α` = 2 | `β` = 0.5, 1, 2, 4 | 예 |
| T5 | 결과 섞기 | `y_i = (1 − λ) ŝ_i + λ · (T2 결과)` | `α` = 1, 2, 4 × `λ` = 0.25, 0.5, 0.75 | 근사적으로 예 |
| T6 | 음원별 강도 | `w_i = (P_i / mean_j P_j)^(α_i/2)`, `M_i = w_i / Σ_j w_j` | (vocals·other, drums·bass)의 `α` = (2, 1), (3, 1.5), (4, 1), other만 4 나머지 2. 마스크만, 그리고 `λ` = 0.25, 0.5로 섞기 | 예 |
| 참고 | 정답 마스크 | T2에서 `P_i` 대신 정답 `|STFT(s_i)|²`, `α` = 2 | 상한선 확인용 (실제로는 사용 불가) | 예 |

T4는 Lebart 등의 통계적 잔향 모델(지수 감쇠)을 잔향 제거가 아니라 "이전 프레임에서 이어지는 잔향 꼬리를 원래 음원에 다시 배분"하는 데 쓴 것입니다. T6에서 모든 `α_i`가 같으면 T2와 같아지는 것을 확인했습니다(차이 0.0 dB).

### 4.3 관찰

1. **추정 마스크로는 의미 있는 개선이 없었습니다.** 1위(T5, +0.06 dB)도 곡 단위 Wilcoxon 검정에서 유의하지 않았습니다(p ≈ 0.08, 10곡).
2. **Mixture Consistency는 고칠 오차가 거의 없었습니다.** HTDemucs 출력 합과 혼합 음원의 차이는 혼합 음원 대비 중앙값 −29.5 dB(가장 큰 경우 −26.1 dB)였습니다.
3. **마스크가 강할수록 누출과 왜곡이 교환됩니다.** `α`=4나 T6에서 SI-SIR이 vocals는 최대 +1.55 dB, other는 최대 +1.04 dB 올랐지만(음원별 중앙값) SI-SAR이 더 크게 떨어졌습니다. 드럼·베이스의 강도를 낮추면 SI-SIR이 약 −3 dB 떨어졌습니다.
4. **RT60을 이용한 T4는 T2(`α`=2)보다 0.06 dB 정도만 나았습니다.** 조건별 최적 설정의 차이도 0.2 dB 미만이라, RT60에 따른 강도 조절의 근거를 찾지 못했습니다.
5. **정답 마스크와의 차이(+4.87 dB)가 큽니다.** 마스크 구조 자체보다, 분리 결과로 추정한 `P_i`가 정답 분포와 다른 것이 한계로 보입니다. 이 해석은 검증하지 않은 가설입니다.

## 5. 후처리와 관련된 오류 분석 결과 (평가용 40곡)

| 음원 | 청취로 확인한 주된 오류 | 40곡 지표 (잔향 없음 → R4, 중앙값) |
|---|---|---|
| other | 누출 (후보 3/3) | SI-SIR 14.63 → 5.54 dB |
| drums | 목표 성분 손실 (3/3, 심벌 등) | target gain 0.90 → 0.63 |
| bass | 목표 성분 손실 (2/2) | target gain 0.91 → 0.55 |
| vocals | 약한 손실 (2/3), 누출 (1/3) | 네 음원 중 변화가 가장 작음 |

- **청취 조건:** 평가자 1명, 후보 11개, 지표가 가장 나쁜 5초 구간으로 청취했습니다. 인공적 왜곡으로 판단한 후보는 없었습니다.
- **베이스 소실:** 잔향 조건 160개 중 12개(6곡)에서 베이스 출력의 target gain이 0.1 미만이었습니다. 정답 베이스를 각 출력에 투영하면, 잔향 없는 조건에서는 bass 0.64, other 0.18이었지만 잔향 조건에서는 bass 0.01, other 0.61로 바뀌었습니다. 12개 중 8개는 other로, 4개는 drums로 주로 옮겨 갔습니다.
- **후처리와의 관계:** T2~T6처럼 `P_i`로 마스크를 만드는 방식은, 출력이 거의 0인 베이스를 되살릴 수 없습니다.

## 6. 다음에 시험할 후보

모두 입력은 2장과 같고(`x`, `ŝ_i`, 선택적으로 `T60`), 출력은 `y_i`(4 × (2, N))입니다.

| ID | 후보 | 처리 | 추가 입력·설정 | 기대하는 점 | 걱정되는 점 |
|---|---|---|---|---|---|
| C1 | 다채널 Wiener 필터 (EM 반복) | `|STFT(ŝ_i)|`를 초기 크기로 두고 음원별 공간 공분산(2×2)과 크기를 반복 추정한 뒤 다채널 Wiener 필터를 적용 (예: `norbert.wiener`) | 반복 횟수, softmask 여부 | 단일 채널 비율 마스크가 쓰지 않은 좌우 패닝 정보를 활용 | 잔향이 좌우에 같게 들어가 공간 정보가 패닝에만 있음 |
| C2 | 혼합 일치 + STFT 일관성 반복 복원 (MISI 계열) | 크기는 `|STFT(ŝ_i)|`로 두고, 위상을 반복 갱신하면서 매 단계 `Σ y_i = x`가 되도록 오차를 나눠 줌 | 반복 횟수, 크기 갱신 여부 | 혼합 음원 위상을 그대로 쓰는 한계를 줄임 | 출력 합이 이미 혼합 음원과 거의 같아 효과가 작을 수 있음 |
| C3 | 저역 재배분 (베이스 소실 대응) | 차단 주파수 `f_c` 아래에서 bass 출력이 other·drums에 비해 매우 작은 시간-주파수 칸만, 해당 에너지를 bass로 옮김 | `f_c`, 판정 임계값 | 베이스 소실 12개 샘플의 복구 | 킥 드럼 등 저역 성분을 잘못 옮길 수 있음, 규칙 기반 |
| C4 | RT60 기반 강도 조절 | C1~C3 중 효과가 있는 방법의 강도(`λ`, 반복 횟수 등)를 `T60`의 함수로 정함 | `T60` | 보고서의 "RT60에 따른 적응형 후처리" | C1~C3에서 개선이 먼저 확인되어야 의미가 있음 |
| C5 | 작은 보정 신경망 | `x`와 `ŝ_i`의 STFT를 입력으로 마스크 보정값을 학습 | MUSDB train 곡으로 만든 잔향 학습 데이터 | 추정 `P_i`의 오차를 데이터로 보정 | 학습 데이터 생성 필요, GPU 없음, 보고서 범위 확인 필요 |

**시험 계획:** C1 → C2 → C3 순서로, 3장과 같은 방법(개발용 40개 샘플, 같은 지표와 집계)으로 비교하려고 합니다. 효과가 있는 방법만 평가용 40곡에서 BSS Eval SDR, 처리 시간, 청취와 함께 최종 비교합니다.

## 7. 여쭙고 싶은 점

1. 6장의 후보 중 해 볼 만한 방향이 있을지, 또는 다른 추천 방법이 있을지 궁금합니다.
2. 입력과 출력의 정의(2장)에서 빠졌거나 바꿔야 할 부분이 있을까요? 예를 들어 `T60`을 입력으로 써도 되는지 궁금합니다.
3. 개선이 작더라도 정답 마스크 상한선과 원인 분석을 함께 제시하는 결과로 정리해도 괜찮을까요?
4. 개선이 어렵다면 분리 전 잔향 감소나 재학습처럼 후처리 범위를 넘어서도 되는지 궁금합니다.
