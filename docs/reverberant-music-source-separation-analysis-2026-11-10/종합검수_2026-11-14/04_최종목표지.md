# 잔향 음악 분리 최종 목표지

2026-11-14 검수 기준. **목표는 잔향이 있는 음악의 네 음원을 원래 잔향까지 포함해 분리하면서, 추가 잔향 없는 음악과 vocals의 성능을 보호하는 것이다.** 현재는 내부 탐색 실험의 개선을 확인했으며 최종 목표 달성이나 배포 적격은 확인하지 못했다.

## 대상과 산출물

입력은 44.1kHz stereo 음악 혼합, 출력은 vocals·drums·bass·other 네 파형이다. 평가 정답은 각 음원의 **wet 이미지**이며 음악에 원래 포함된 잔향·효과를 보존한다. 여기서 dry는 ‘추가 합성 RIR 없음’이라는 실험 이름이다. 원래 녹음이 무향실 신호라는 뜻은 아니다.

주 기준선 B는 현재 등록된 HTDemucs와 BS-RoFormer의 50:50 파형 평균으로 고정한다. 초기 SCNet rev는 미세조정 효과의 대조군이며 B를 대체하는 최종 기준선이 아니다. 새 방법은 실제 추론에서 원음원 정답·RIR 라벨·곡별 oracle 선택을 사용하지 않아야 한다.

최종 산출물은 고정된 추론 코드·가중치/선택기·설정·재현 명세, 학습 데이터 출처/분할 감사표, 봉인된 최종 평가 결과, 실패곡·청감 예제와 실행 비용표다.

## 목표 수준과 현재 위치

| 수준 | 필요한 근거 | 현재 판정 |
|---|---|---|
| 계산·실행 신뢰성 | 같은 입력·정답, 모델/코드/출력 추적, 지표 재계산 일치 | 최근 주요 수치는 확인. 이번 검수의 전 파형 재추론은 수행하지 않음 |
| 내부 방법 효과 | 실험별 고정 대조에서 추가 효과 확인 | SCNet 미세조정의 초기 rev 대비 +0.509dB 등 확인 |
| B 대체 후보 | wet 개선과 dry/음원 보호를 함께 만족 | 선택기는 기존 중앙값 기준 통과. dry 2곡 손상·합 불일치가 남음 |
| 최종 일반화·실사용 | 독립 곡/공간, 개별 실패 통제, 청감·비용, 고정 방법 | 미달성. 아래 평가가 필요 |

## 최종 성능 목표안

아래 수치는 **앞으로 고정할 최종 평가 규격의 제안**이다. 기존 실험의 사전 기준을 소급 변경하거나 현재 결과를 이 기준으로 성공 선언하지 않는다. 현재 파일들의 `accepted=true`는 해당 실험의 제한된 기준 통과만 뜻한다.

| 항목 | 최종 목표안 | 현재 증거/공백 |
|---|---|---|
| wet 전체 | B 대비 곡별 유효 음원 평균 ΔSI-SDR 중앙값 **≥+1.0dB**, 95% CI 하한>0 | 입력 선택기 +1.460 [0.080,2.062]은 노출 validation 결과 |
| dry 전체 | 대응 중앙값 CI 하한≥−0.2dB | 선택기 0.000 [−0.155,0.000]으로 기존 중앙값 기준 통과 |
| 개별 dry 곡 | 각 곡의 전체 ΔSI-SDR ≥−0.2dB; 손상곡 수·최악·하위5% 함께 보고 | St Vitus −0.310, Titanium −2.202로 미충족 |
| vocals/other 보호 | wet·dry 각 음원 대응 CI 하한≥−0.2dB | 현재 결합/선택기는 B의 해당 파형 복사로 보존. 향후 모델 변경 시 재검증 |
| bass 개선·소실 | 활성 bass ΔSI-SDR 중앙값≥+1.0dB/CI하한>0을 제안, B 대비 새 저투영 소실 사례0; 소실률 CI·출력 RMS 병기 | 선택기 새 소실0, 기존 wet1/9는 남음. 활동도 규격 미확정 |
| 합·왜곡 | 곡별 상대 합잔차RMS 차이의 중앙값 CI상한≤+0.01, wet SI-SAR 차이 중앙값 CI하한≥−0.5dB를 제안; 청감 병행 | 선택기 wet 합잔차 중앙값0.1813 vs B0.0545. 강제합 보정은 분리 성능 악화 |
| 수치적 합일치를 주장하는 방법 | 전체 파형 최대 절대오차≤3e−6와 보호 파형 검사 | 보정은 2.98e−8 달성했지만 성능 기준 실패. 합일치는 충분조건 아님 |
| 실행 비용 | 같은 하드웨어에서 B 대비 추가 처리시간 중앙값≤20%를 초기 예산안으로 측정 | 전용·동일 부하의 end-to-end 측정 미완료. 과거 공유 GPU 로그를 정식 지연 비교로 쓰지 않음 |
| 재현성 | 소스·설정·데이터·체크포인트 hash, 원시 지표, 실패와 제외 사유 보존 | 기존 binding을 유지하고, 설정에 쓰인 값과 실제 판정 상수를 일치시킬 것 |

활성 bass의 활동도 규격과 청감 과제/판정 방식은 P0에서 train 개발 자료로 확정해야 한다. 위 추가 효과·잔차·SI-SAR 수치는 프로젝트의 제안 허용차이며 보편적인 문헌 표준이 아니다. 이 규격이 미정인 상태에서는 최종 테스트를 개봉하지 않는다.

관측한 모든 dry 곡에서 손상이 없더라도 모집단의 실패 확률0을 증명하는 것은 아니다. 손상곡 수와 분모, 표본 수에 따른 상한을 함께 보고한다. 정확무음/저에너지 음원은 별도 지표가 필요하다. 활동도 기준은 train 개발 단계에서 고정하고 최종 테스트 결과를 본 뒤 바꾸지 않는다.

## 평가 데이터의 세 층

1. **현재 validation10:** 방법 설계·실패 분석·checkpoint 선택에 이미 반복 사용됐다. 지금 수치는 탐색적 비교에 쓴다. bootstrap은 이 설계·선택 과정의 낙관성까지 보정하지 않는다.
2. **내부 confirmation10:** 우리 추가 학습·선택기 조정에는 아직 쓰지 않았다. 하지만 MUSDB 공식 train에 속한다. BS-RoFormer의 공식 train100 학습 선언과 중복되며, SCNet 공개 recipe상으로도10곡 모두 author train에 포함된다(실제 checkpoint 생성 목록은 별도 확인 필요). 따라서 ‘모든 모델에 대한 미사용 곡’은 아니다. 방법을 잠근 뒤 내부 확인용으로 한 번 사용한다.
3. **최종 외부 테스트:** 사용하는 모든 backbone의 학습·검증 출처와 곡/연주/마스터 단위 중복을 점검한 자료가 필요하다. 모르는 출처는 ‘비중복 확인’으로 처리하지 않는다. 새 방·IR·실제 stereo 공간 응답도 분리해 평가한다.

초기 모집 계획은 곡 30개 이상과 미사용 공간 3개 이상으로 잡되, 이 숫자가 검정력을 보장하지는 않는다. train 개발 자료의 효과 분산·목표 CI 정밀도로 최종 표본 수를 산정해 테스트 개봉 전에 고정한다. 같은 곡의 여러 RIR를 독립 곡처럼 세지 않는다. 곡 단위 집계와 방별 결과를 함께 보고하고, 충분한 공간 수가 확보되면 곡·공간 계층을 반영한 재표집을 사용한다.

## 실험 우선순위와 종료 기준

| 순서 | 실행할 일 | 결정/종료 조건 |
|---|---|---|
| P0 | 데이터 중복 감사, 활동도/무음 규격, 평가·판정 코드의 설정 일치, 최종 기준선 고정 | 최종 평가의 의미와 지표 규격을 먼저 확정 |
| P1 | train 곡에서 B/H의 실제 성능 차이·손실 비용을 라벨로 하는 품질 선택기 | 같은 구조·입력 특징으로 RIR 분류 라벨과 품질 라벨을 대조. 곡 단위 train 내부 검증으로 교정 |
| P2 | 필요 시 dry/wet 비율·vocals 가중·teacher 보존의 하나씩 대조하는 학습 | 한 번에 한 요인만 바꿔 효과를 분리. pilot 신호가 없으면 장시간 학습 확대 중단 |
| P3 | 방법 하나·threshold·평가 규격 동결 후 내부 confirmation | 결과를 보고 동결을 풀면 이 세트는 더 이상 최종 확인 세트가 아님 |
| P4 | 외부 비중복 곡/공간·블라인드 청감·실행 비용 평가 | 목표안의 품질·실패·자원 조건을 함께 만족할 때 최종 채택 검토 |

실험 실패도 산출물이다. 실패한 주후보를 사후에 다른 대조군으로 바꾸어 성공으로 쓰지 않는다. 모든 임계값 조정은 train 내부 개발에서 수행하고, 새 검증 세트가 필요해졌다는 사실을 기록한다. 현재 운영 비교 기준은 B이며, 선택기는 연구 후보로 보존한다. 두 drums/bass 강제 잔차배분은 현재 설정에서 미채택이다.
