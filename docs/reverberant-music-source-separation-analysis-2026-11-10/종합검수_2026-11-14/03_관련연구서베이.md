# 관련 연구 서베이와 적용 범위

2026-11-14 원문 확인 범위는 아래 핵심11편과 명시한 저자 구현이다. 기존 [문헌 전체 목록](../문헌_전체목록.csv) 96건 전체를 이번에 재검증한 것은 아니다. 논문이 사용한 데이터·정답·지표와 우리 변경점을 구분한다. 논문 SDR 수치를 우리 ΔSI-SDR 결과와 합산하지 않는다.

## 원문과 우리 실험의 연결

| 연구/출판 상태 | 원문 대상·검증 내용 | 우리 실험에 쓰는 근거와 한계 |
|---|---|---|
| [HT Demucs — Rouard 외, ICASSP2023](https://arxiv.org/abs/2211.08553) | 스튜디오 음악4stem, 시간/주파수 경로의 Transformer. 추가 데이터·모델별 조건에서 높은 SDR | 강한 기준선의 근거. 논문 최고9.20dB를 현재 `htdemucs` checkpoint나 잔향 성능으로 전용하지 않음 |
| [BS-RoFormer — Lu 외, ICASSP2024](https://arxiv.org/abs/2309.02612) | band split·RoPE·Transformer 음악 분리. 작은 모델/no-extra 조건과 SDX 추가500곡 조건 구분 | HTD와 상보적 기준선. 현재 MSST ep17의 학습 명세는 해당 [모델 카드](https://github.com/ZFTurbo/Music-Source-Separation-Training/blob/f17924ddb1817cdbae6353706708c4518dd7cd14/docs/pretrained_models.md)로 따로 추적 |
| [SCNet — Tong 외, ICASSP2024](https://arxiv.org/abs/2401.13276) | 주파수 대역별 압축률과 dual-path 구조, 스튜디오 음악4stem | 제한된 GPU에서 미세조정한 backbone. 구조 자체가 잔향 문제를 해결했다는 증거는 아님. [저자 구현](https://github.com/starrytong/SCNet) |
| [CrowdioSet/PaRIRset — Gusó·Serra, ISMIR2026](https://arxiv.org/html/2607.27828v1) | 실제 PA RIR·관객 소음, **wet 출력과 wet 정답**을 보존. venue를 나눈 검증 | 현재 목표에 가장 직접적. §5의 pure-rev는 모델들이 비슷하다고 서술하며 표2는 noisyrev. clean/rev 학습률도 달라 RIR 단독 인과효과로 확정 불가. [공식 발표](https://ismir2026program.ismir.net/poster_51.html) |
| [NARA-WPE — Drude 외, ITG2018](https://groups.uni-paderborn.de/nt/pubs/2018/ITG_2018_Drude_Paper.pdf) | 음성 late reverberation 억제, direct/early 보존. offline/online WPE 구현 | 입력 전처리 대조로 적합. full-wet 음악 정답과 목표가 달라 검증 없이 개선을 기대할 근거는 없음. [구현 설명](https://nara-wpe.readthedocs.io/en/latest/) |
| [FCP — Wang·Wichern·Le Roux, TASLP2021](https://arxiv.org/abs/2108.07376) | 음성 direct-path 추정과 convolutive prediction, REVERB/SMS-WSJ/WHAMR | 학습과 선형 예측을 결합하는 참고. direct-target 음성 결과를 full-wet 음악4stem으로 직접 이전할 수 없음. [저자 논문](https://zqwang7.github.io/publications/taslp2021_fcp.pdf) |
| [Differentiable Consistency Constraints — Wisdom 외, ICASSP2019](https://research.google/pubs/differentiable-consistency-constraints-for-improved-deep-speech-enhancement/) | 음성+잡음의 STFT/mixture projection을 네트워크 학습에 결합. 해당 음성 실험 SI-SDR 개선 | 합 보존 원리는 일반적. 우리 vocals/other 고정·DB만 배분·에너지 proxy는 별도 설계. 이번 실패는 두 로컬 배분 방식의 실패이며 논문 전체의 반증 아님. [원문](https://arxiv.org/pdf/1811.08521) |
| [Model Selection via Clustering Analysis — Liu 외, DCASE2020](https://interactiveaudiolab.github.io/assets/papers/liu_dcase20.pdf) | deep-clustering embedding의 silhouette와 posterior confidence로 **GT 없이 품질 기반 선택**. 음악은16kHz/5초 vocals-accompaniment2source | 품질 선택의 선행 근거. 원문 음악 mean SDR confidence6.4/oracle6.5/random4.2는 우리 조건 수치가 아님. 현재33특징 logistic RIR 분류기는 원문 알고리즘 재현이 아님 |
| [An Ensemble Approach to MSS — Vardhan 외, arXiv2024 preprint](https://arxiv.org/html/2410.20773v1#S4.SS2) | §4.2에서 **GT stem으로** SNR/SDR를 계산해 곡·stem별 harmonic mean 최고 출력 선택 | 음원별 상보성과 oracle 진단의 근거. 실사용 GT 없는 선택 성능의 근거로 쓰면 안 됨. 정식 출판 상태는 이번 확인 범위에서 미확인 |
| [SDR—Half-Baked or Well Done? — Le Roux 외, ICASSP2019](https://arxiv.org/abs/1811.02508) | BSS_eval SDR의 오용/실패를 분석하고 SI-SDR 평가 정의 제안 | SDR/SI-SDR·프레임/곡 집계를 혼용하지 않을 근거. scale invariance 때문에 음량 소실은 gain/RMS 별도 확인. [기관 출판 기록](https://www.merl.com/publications/TR2019-013) |
| [Perceptual Errors in MSS: Looking Beyond SDR Averages — Sarkar 외, ISMIR2025](https://ismir2025program.ismir.net/poster_221.html) | 여러 음원 구분 과제의 청취 평가, 평균 SDR가 숨기는 오류와 문맥 의존성 | 평균·중앙값 외에 실패 분포·음원별 오류·청감을 포함할 근거. [저자 기관 원문](https://qmro.qmul.ac.uk/xmlui/bitstream/handle/123456789/107959/Benetos%20Perceptual%20errors%20in%20music%202025%20Accepted.pdf?isAllowed=y&sequence=2) |

각 논문의 성능값은 그 논문의 모델·데이터·정답·집계 아래에서만 유효하다. 프로젝트의 +0.2dB, −0.2dB, gain<0.1 등은 **운영 기준**이며 문헌이 정한 보편적인 표준이 아니다.

## PaRIRset 공개 recipe와 내부 분할

고정 commit `600585bc0d50cb48dd64e4602e3c34fe48be7347`의 [prepare_musdbmoises.py](https://github.com/enricguso/guso_ismir26/blob/600585bc0d50cb48dd64e4602e3c34fe48be7347/prepare_musdbmoises.py#L35)는 MUSDB train100 중14곡을 author validation으로 옮긴다. [wav.py](https://github.com/enricguso/guso_ismir26/blob/600585bc0d50cb48dd64e4602e3c34fe48be7347/scnet/wav.py#L171)가 train/valid 폴더를 구분한다. ‘공식 SCNet이 MUSDB train100곡 모두를 최적화에 사용했다’고 단정하는 표현은 수정해야 한다.

| 우리 분할 | 공개 recipe의 author train | author validation |
|---|---:|---:|
| train80 | 69 | 11 |
| validation10 | 7 | 3 |
| confirmation10 | 10 | 0 |

우리 validation 중 author validation에 해당하는 곡은 Clara Berry And Wooldog - Waltz For My Victims, Johnny Lokke - Promises & Lies, Skelpolu - Human Mistakes다. 이미 valid 폴더가 있으면 분할을 새로 만들지 않는 코드 조건이 있어, 이 표는 **공개 기본 recipe 대조**다. 배포 checkpoint의 실제 학습 manifest를 확보한 판정은 아니다. 준비 스크립트 SHA256은 `ee146f4308aa0a18bd5a6324334ff3001a0c2c1b8a1c277eacc235f412283fb9`이다.

따라서 우리 confirmation10곡은 추가 미세조정에 미사용한 자료이지만, 공개 backbone 기준의 독립 일반화 테스트로 해석할 수 없다.

## 서베이에서 도출한 실험 방향

- **유지:** wet-target 잔향 증강/분리기 적응. 우리 미세조정의 추가 효과는 확인했지만 요인 분리와 외부 검증이 필요하다.
- **우선:** 품질 차이·손실 비용 기반 선택. train 곡에서 B/H 실제 이득을 라벨로 삼고 추론에서는 입력/출력 특징만 사용한다. 현재 RIR 라벨과 같은 구조·조건으로 대조해 라벨 목표의 효과를 분리한다. 필요한 train B/F 예측 cache가 모두 준비됐다고 가정하지 않는다.
- **보조:** teacher 보존 또는 dry/wet 비율/손실 가중의 하나씩 대조. 단순 학습 연장과 여러 변경을 동시에 섞어 원인을 단정하지 않는다.
- **현 설정 미채택:** blind EQ, WPE 단독, 소형 보정망의 미미한 효과, DB 강제 잔차 배분을 최종 해결책으로 확정하는 접근.
- **최종 검증 필수:** 곡과 공간의 노출을 분리한 테스트, 저에너지 음원·실패 분포·청감·실행 비용. 논문 인용은 이러한 실제 검증을 대체하지 않는다.
