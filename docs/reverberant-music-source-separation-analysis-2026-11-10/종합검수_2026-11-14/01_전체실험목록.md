## 변형·폐기·미실행을 구분하기

- E01의21개는 identity 제외 등록 후보이며 Wiener2는 `invalid-observations`다. 실제 Holm family20개와 등록22개(identity포함)를 혼동하지 않는다. small/large/XL의 dev 비교와 선정 앙상블 eval40을 같은 검증 수준으로 쓰지 않는다.
- E05의 신규추론60개와 재사용50개가110조건표를 구성한다. 초기반사 절단은 색채·위상·gain도 바꾸므로 RT60 하나만의 효과가 아니다.
- E08 무효run: `c65e…` 입력95.11초/DSP380.44초,2회 후무효. `5a10…` 입력190.22초/DSP380.44초,14회pilot 후경계오차로중단. 최종 `c2ea…`는 **입력190.22초/DSP760.87초**,14+126=140회다. ‘380초 입력 실험’이라 쓰지 않는다.
- `TRAINING_STATUS.md`의100회, `RUN_STATUS.md`의중단/복구 문구는 과거 snapshot이다. 최신 완료는 refiner3000회, cause-EQ140회다. 준비파일의 optimizer0도 현재 학습 상태가 아니다.
- 준비된 confirmation40cache는 HTD 예측/자료 준비다. 새로운 refiner·SCNet·selector의 최종 확인 평가를 완료했다는 뜻이 아니다.
- 소수곡 overfit, extended loss, mixture-only/one-stem ablation, 문맥6~8초 대조,20k·3seed 확대, 실제 stereo RIR, 새녹음12~20곡, 정식청취/BSS Eval, RT60 적응 강도, 품질차 기반 선택기는 완료 근거가 없는 계획으로 남는다.
- 초기 C3 규칙 기반 저역 이전과 완료된 donor 재분리/bass 이전은 같은 실험이 아니다. WPE/성분 절단/direct-target 연구를 원래wet성분 보존과 혼합하지 않는다.

## 앞으로 실행할 목록

목표지는 [최종 목표지](04_최종목표지.md)에 있다. 다음 실험은 **데이터 노출·활동도 규격 정리 → train 내부 품질이득 선택기 대조 → 학습 요인 분리 → 방법 동결 → 내부 확인/외부 검증** 순서다. 새 train B/F 출력 cache 생성 비용은 실제 필요한 범위를 점검한 뒤 측정해야 하며, 이미 전부 준비됐다고 가정하지 않는다.
