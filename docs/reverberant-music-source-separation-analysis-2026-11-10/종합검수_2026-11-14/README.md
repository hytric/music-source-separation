# 잔향 음악 분리 전체 실험 검수와 최종 목표

2026-11-14 기준. **분리기 적응과 입력 선택의 내부 개선은 확인했다. 그러나 새 곡·새 공간에서의 일반화, 개별 dry 손실, 청감·음원합 보호까지 충족한 최종 방법은 아직 없다.** 최종 목표는 원래 잔향을 보존하는4음원 분리에서 기존 HTDemucs+BS-RoFormer 앙상블보다 좋아지면서 dry와 vocals를 보호하는 것이다.

## 현재 확인된 성능

아래 수치는 같은 내부 validation10곡의 dry/wet_R4,40초입력·중앙30초 결과다. 비교 기준이 다른 수치를 누적하지 않는다.

| 방법 | 대조 | wet 전체 ΔSI-SDR [95% CI] | dry 전체 ΔSI-SDR [95% CI] | 판정 |
|---|---|---|---|---|
| SCNet1,000회 미세조정 | 초기공식rev | +0.509 [0.286,0.902] | +0.182 [0.057,0.239] | 추가학습 효과 확인 |
| 미세조정SCNet | 기존앙상블 B | +1.531 [0.173,2.243] | −2.154 [−2.561,−1.777] | 전입력 교체 불가 |
| 음원별 고정결합 | B | +1.577 [0.725,2.079] | −1.253 [−1.424,−0.846] | dry 보호 실패 |
| 입력만 쓰는 선택기 | B | +1.460 [0.080,2.062] | 0.000 [−0.155,0.000] | 기존 중앙값 기준 통과, 개별 dry2곡 손상 |
| 선택기+DB에너지합보정 | B | +1.037 [0.066,1.423] | −0.026 [−1.064,−0.014] | 합일치 성공, 성능 보존 실패 |

현재 연구 대표 후보는 **미보정 입력 선택기**다. vocals/other를 B 그대로 보존하고 wet 개선이 있으나 St Vitus−0.310/Titanium−2.202dB 손상이 남는다. 운영 대조는 B로 유지하고 배포 적격은 보류한다. 새 품질차 기반 선택기는 아직 구현·검증하지 않았다.

## 검수에서 달라진 판단

1. 최근CSV2,580행에서68조건비교의중앙값/CI를재계산했고저장된수치와차이0이었다. 수치의일치와일반화입증은다르다.
2. 내부validation/confirmation은공식MUSDB train에서나왔다. BS-RoFormer 모델카드상학습중복근거가있고, 공식SCNet recipe상confirmation10도authortrain에속한다. **내부confirmation을모든backbone에미노출인새곡평가라고부를수없다.**
3. 같은10곡을반복설계·후보선택에사용했다. 각실행을고정했어도현재CI가연구전체의선택낙관성을반영하는것은아니다.
4. 출력합보정의Matthew−2.808dB는거의무음bass의SI-SDR에크게좌우된다. 출력bassRMS는감소했으므로전체청감악화로번역할수없다. 사후활동도민감도를추가했지만기존판정은바꾸지않았다.
5. 품질기반선택논문과현재RIR분류기는다른방법이다. 다른앙상블논문은GT로출력을선택하므로실사용선택근거로전용하면안된다.

## 앞으로의 목표와 실행 순서

최종 목표안은 독립 평가에서 **B 대비 wet 중앙값≥+1.0dB/CI하한>0**, dry·vocals 보호와개별손실통제, bass오류·합잔차·청감·실행비용을함께만족하는것이다. 이수치는앞으로고정할제안규격이며기존실험을소급판정하지않는다.

먼저 데이터 노출 장부와 활동도/평가 규격을 확정한다. 다음은 train 곡의 실제 B/H 이득과손실비용으로선택기를학습하는대조다. 필요하면학습비율·손실가중치를한요인씩분리한다. 방법을동결한뒤내부confirmation,외부비중복곡/공간,청감·실행비용평가로이어간다. 현재자료만으로목표달성이나논문기여의독창성을확정하지않는다.

## 검수 범위

이번 작업은 자료·코드·원문 검수와 저장지표 재집계다. 새 모델학습/GPU추론·confirmation평가는 실행하지 않았다. 초기자료는원보고/원JSON/상태와대조했고,새로재계산한68조건은최근5개음원CSV와선택CSV에한정한다. 핵심11편을확인했으며기존96개문헌목록전체를재검증했다고하지않는다. [정량 근거](정량검수근거.json)와[서베이 근거](서베이_검수근거.json)를함께보존했다.

## 재계산 실행

`python recompute.py --project /원래/seperation`과 `python activity_sensitivity.py --project /원래/seperation --hybrid-runtime /stem-hybrid-v1`로 숫자를 다시 확인할 수 있다. 기존 실험 CSV와후자의mixture RMS 기록이필요하며새학습이나추론은수행하지않는다. 민감도분석은사후보조분석으로서원래판정을대체하지않는다.
