# 예상 결과와 성공 조건

새 QG1 실험은 아직 구현·실행하지 않았다. 아래 예상은 검증할 가설이고, 숫자는 과거 실측 또는 앞으로 적용할 목표다. 새 모델의 점수·신뢰구간·종료시각을 미리 실측값처럼 작성하지 않는다.

## 1. 실측 기준점

같은 노출 validation10곡/20조건에서 B 대비 현재G0는 wet전체+1.460dB [0.080,2.062], dry중앙값0.000 [−0.155,0.000]이었다. dry2곡(StVitus−0.310,Titanium−2.202)이손상됐다. F1000단독은wet+1.531/dry−2.154,항상H는wet+1.577/dry−1.253이었다. 원래wet소실은B/G0모두1/9이며새소실0이다.

이 값은 새64fit 모델이나 새 곡의 예측값이 아니다. 특히G0가64fit/16교정의C와같은모델이라고취급하면안된다. 과거수치는재현확인의기준이고Q의목표는실제비교로판단한다.

## 2. 검증할 가설

| 가설 | 기대하는 관측 | 반례/실패 해석 |
|---|---|---|
| 품질 라벨이 RIR 라벨보다 목적에 맞음 | C보다Q의잘못된선택/큰dry손실이줄고wet이득유지 | Q와C가비슷하면라벨만바꾼효과미확인 |
| 보수적 교정이 큰 손실을 줄임 | fit계수고정상태에서cal16의위험선택이줄어듦 | 항상B만남으면안전fallback일뿐개선실패 |
| 입력33특징만으로 이득을 어느 정도 예측 가능 | Q가val에서정답없이이득을보존 | 실패하면특징정보부족/분포이동/라벨잡음가능성;정답누수나threshold재조정으로해결금지 |
| 내부 개선이 다른 공간·곡에도 이어짐 | 동결후미사용조건에서재현 | 이번val10의결과만으로이일반화가설은판정불가 |

유효한 Q 라벨 수, oracle 이득과 위험 분포를 train/calibration에서 먼저 확인한다. oracle도 이득이 작다면 선택기만 개선해 큰 성능을 기대할 근거가 없다. 점수의 ‘예상 범위’를 임의로 +2~3dB처럼 만들지 않는다.

## 3. 세 단계의 성공 판정

### 구현 성공

필수320조건/teacher960출력의coverage·hash·shape·source순서·정렬·FP32가맞고,64/16분리가지켜지며,라벨/교정/추론인터페이스테스트를통과해야한다. 계수·표준화는교정전후같고기존G0를val20에서오차허용내재현해야한다. 성공조건을채점하는코드는protocol에서값을읽고,설정에없는상수를사용하지않는다.

구현 성공은 성능 성공이 아니다. 구현/자원 오류가 있으면 과학적 실패와 구분해서 보고한다.

### QG1 내부 pilot 성공

다음은 새로운 실행 전에 고정하는 Q의 기본 pilot 기준이다. 과거 실험의 판정을 소급 변경하지 않는다.

| 항목 | 기준 |
|---|---|
| wet 개선 대 B | 곡별유효음원평균ΔSI-SDR 중앙값≥+0.2dB,95%CI하한>0 |
| 현재효과 보존 대 G0 | wet전체대응차이의CI하한≥−0.2dB |
| dry 평균적 보호 대 B | 전체대응차이중앙값CI하한≥−0.2dB |
| 개별dry 보호 대 B | 각dry곡전체Δ≥−0.2dB,손상곡0/10 |
| vocals/other | B와파형byte동일;지표동일성검사 |
| bass | B대비새gain<0.1소실0;dry·wet 각각 활성bass대응CI하한≥−0.2dB |
| 왜곡 | wet전체SI-SAR 차이 대 G0의CI하한≥−0.5dB |
| 유효작동 | always-B가아니고wet실제선택과개선이있음 |

전체조건을동시에만족해야`pilot_safe_effect=true`다. baseline사용곡이많아median이0이어도개별dry보호를통과했는지따로본다. active보조판정이좋아도legacy주지표를빼지않는다. 필수입력20조건과보호byte검사20건,primary의유효곡수dry10/wet10,wet SI-SAR10곡,활성bass각조건8곡이상,유효bassgain쌍각조건8곡이상을요구한다. 이최소수는고정pilot의운영규격이며검정력보장이아니다. 미정의/관측부족은통과가아닌`insufficient_evidence`로기록한다. 보호음원정답이무음이면SI-SDR를임의0으로만들지않고byte보존과유효표본수를보고한다.

**라벨 효과 대조:** Q가pilot기준을통과하고wet Q−C의CI하한≥−0.2dB이면서C보다dry손상곡수가적으면‘내부표본에서위험선택감소를관측’으로기록한다. 두모델모두dry손상0이면Q−C wet중앙값≥+0.2dB/CI하한>0일때추가이득을기록한다. 그렇지않으면Q가B보다좋더라도‘품질라벨의추가효과미확인’이다. 소표본손상건수차이를모집단위험감소의확정증거로확대하지않는다.

### 최종 목표/배포 적격

이번실행의`final_goal_eligible`와`deployment_ready`는false다. 내부validation을이전에보지않은세트로명명하지않는다. 최종목표지의wet+1.0dB,외부비중복곡/공간,합잔차·청감·실행비용등은별도동결평가가필요하다. pilot통과후에도입력합오차가증가하면그상태를보존해보고한다. 실패한DB강제보정으로수치만0으로만들지않는다.

## 4. 지표의 정확한 집계

각record에서유효stem의대응Δ를먼저평균한다. calibration의wet은같은곡의3RIR를평균한뒤16곡중앙값으로threshold를고른다. validation은dry10/wet_R4 10을별도로집계한다. CI는seed20261114,10,000회곡단위bootstrap의중앙값percentile[2.5,97.5]다. 같은곡의여러RIR를독립곡으로재표집하지않는다. 4개음원의중앙값을평균하거나두방법의중앙값을빼서대응차이로대체하지않는다.

반드시legacy/active보조지표,표본수와제외사유,곡별Δ,손상곡수,최악/하위5%,gain/RMS,무음bass오출력,상대합잔차RMS,SI-SAR,route를함께저장한다. GT활동도mask는평가/라벨용이고추론특징에넣지않는다. 거의무음인Matthew bass처럼SI-SDR와청감의의미가다를수있으므로전체청감악화라고번역하지않는다.

## 5. 결과별 후속 행동

| 결과 | 기록 | 후속 행동 |
|---|---|---|
| 계약/누수/수치 오류 | implementation_failed | 오류를고쳐동일코드/데이터계약을검증. 무효결과와유효결과를섞지않음 |

## 6. 제출 형식

결론문 예: “Q의B대비wet효과는실측값[CI],dry손상은실측건수/10이다. 구현계약은검증상태,사전pilot기준은통과/실패다. C대비라벨효과는관측/미확인이고외부일반화와배포는미검증이다.” 숫자는실제출력에서채우며원하는목표값을결과칸에넣지않는다.
