# 향후 구현 모델용 실험 가이드

**이 묶음을 하위 모델에게 전달하면 QG1 품질 이득 선택기 실험의 구현·준비·실행·판정 범위를 확인할 수 있다.** 지금 작성한 것은 명세와 설정 템플릿이며, 새 teacher 추론이나 선택기 학습을 실행한 결과가 아니다.

첫 구현 대상은 실제 B/H 이득과손실을라벨로학습하는Q선택기다. 같은구조의RIR분류기C와비교해학습목표변경의효과를본다. 기존B/H/G0는고정대조로보존한다. 실제추론은혼합입력33특징만쓰고정답/조건라벨을받지않는다.

## 반드시 지킬 핵심

1. **train320의 기존 HTD 출력은30초다.** 새40초teachercache로재사용하지않는다. BSR/F만추가하면되는작업이아니며동일40초입력으로세모델예측을준비한다.
2. train80에서곡hash로64fit/16calibration을먼저고정한다. C/Q는같은33특징·표준화·조건기반sample weights·L2·교정grid를쓴다. 교정후64/80곡재적합은금지한다.
3. Q주후보·라벨식·threshold교정·성공조건을결과전에잠근다. validation결과를보고threshold나실패제외규칙을바꾸지않는다.
4. **항상B는효과성공이아니다.** 구현오류·자원부족·과학적실패·pilot통과·배포적격을구분한다.
5. 과거validation10은이미노출됐고confirmation10도backbone독립자료가아니다. 이번기본실행은노출validation까지만이며새최종검증을한것처럼보고하지않는다.

## 기대 결과의 수준

기존G0의wet+1.460dB, dry중앙값0과2곡손상은비교기준이지Q의예상실측치가아니다. 기대가설은“품질라벨이위험한선택을줄이면서wet이득을보존한다”이다. Q가항상B만선택하거나안전성과wet개선을동시에못만족하면실패로보고한다. 새숫자/CI를사전에채우지않는다.

pilot성공은B대비wet≥+0.2dB/CI하한>0, G0대비wet보존, dry중앙값과개별곡보호, VO보존·새bass소실0 등을동시에만족하는것이다. 최종wet+1.0dB·외부비중복자료·합/청감/비용목표는별도다. [기존 최종목표지](../04_최종목표지.md)를함께읽는다.

## 자원과 미완료 사항

현재알려진자산에는train320용40초teacher출력이없다. 기본저장약58.71GB이며가용80GB를확인한다. 과거40초val호출시간을320조건에단순환산하면약3.16시간이지만I/O·합성·라벨·현재GPU공유부하는미포함이다. 실제pilot시간으로다시산정한다. 다른GPU작업을중단하거나CPU/FP16으로조용히전환하지않는다.

이번작성에서실행한것은자산/코드확인,템플릿/문서검증,동료검토뿐이다. `quality_gate` CLI는목표인터페이스이며아직구현되지않았다. 실제실행자가선행검사를마치고새protocol.lock.json/run ID를만들어야한다. 문서상의예상시나리오를결과로제출하지않는다.
