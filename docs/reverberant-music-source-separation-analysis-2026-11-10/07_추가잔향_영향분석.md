# 추가 잔향 영향 분석 결과

기존 모델 결합 평가 뒤, 사용자의 요청에 따라 원본 분리와 잔향 입력 분리의 차이를 추가 진단했다. **50곡의 추가 잔향 없는 HTDemucs 분리를 새로 실행**하고 기존 R1~R4 출력을 비교했다. 다른 모델 결합의 원본 조건 효과를 평가한 것은 아니다.

| 음원 | 같은 곡의 R4−원본 SI-SDR 변화량 중앙값 |
|---|---:|
| vocals | −4.51 dB |
| drums | −8.88 dB |
| bass | −14.51 dB |
| other | −5.10 dB |

원본 bass 소실은 0/50곡이었고, 잔향 4조건에서는 합계 41/200조건(18곡)이었다. 새 소실 사례의 bass 성분 투영 계수는 bass 출력에서 0.778→0.012, other 출력에서 0.126→0.727로 변했다. 이는 에너지 이동 비율이 아니다. 41개 중 23개는 출력 RMS도 정답의 10% 미만이었고, 18개는 출력이 그 이상 남지만 정답과의 일치 성분이 약했다.

따라서 우선 확인할 문제는 **베이스·드럼의 목표 성분 손실과 other의 누출 증가**다. 후기 잔향과 초기 반사·색채·전파 지연의 영향은 다음 대조에서 나눠야 한다. 해당 추가 대조는 아직 실행하지 않았다.
