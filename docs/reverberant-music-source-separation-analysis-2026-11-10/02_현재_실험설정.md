# 현재 실험 설정

## 1 연구 질문과 입력·출력

질문은 “추가 잔향이 있는 음악에서 고정된 사전학습 분리기가 만드는 누출·손실을 측정하고, 새 학습 없이 개선할 수 있는가”다.

원래 제공된 stem을 `u_i`, 음원별 RIR을 `h_i`라 한다. 현재 정답은 `s_i = g_i × crop(u_i * h_i)`이고 혼합은 `x = Σ_i s_i`다. `*`는 컨볼루션, `g_i`는 해당 원 stem과 RMS를 맞추는 이득이다. 처리 결과 `y_i`를 `s_i`와 비교한다. **정답에서 잔향을 제거하지 않는다.** 원래 MUSDB stem에 제작 단계의 잔향이 있을 수 있으므로 `u_i`를 무향실 원음이라고 부르지 않는다.

| 항목 | 고정값 |
|---|---|
| 음원 순서 | vocals, drums, bass, other |
| 입력 혼합 | `(2, 1,323,000)` float 파형 |
| 기준·최종 출력 | `(4, 2, 1,323,000)` |
| 표본화율·길이 | 44,100 Hz, stereo, 30초 |
| 개발 자료 | 10곡 × R1~R4 = 40개 곡·조건 |
| 평가 자료 | 40곡 × R1~R4 = 160개 곡·조건 |
| 구간 | 곡 중앙 30초. 곡별 manifest에 기록 |
| 분할 | MUSDB18-HQ 공식 test 50곡 안에서 이름 정규화·SHA256 순서와 salt `banelp-v1`로 고정 |
| 학습 | 현재 실행에는 없음 |

이는 공식 MUSDB train/test 전체를 사용한 표준 학습 벤치마크와 다르다. 곡별 30초 crop과 추가 RIR, 자체 지표·집계가 있으므로 논문 표의 SDR 수치와 직접 순위를 비교하지 않는다. [MUSDB 공식 설명](https://sigsep.github.io/datasets/musdb.html)

## 2 잔향 생성

| 항목 | 값 |
|---|---|
| 생성기 | gpuRIR, 고정 소스 버전 `06da27dd` |
| 공간 크기 | 7.5 × 6.0 × 3.0 m |
| 수신기 | 무지향 1개, `(3.73, 0.87, 1.50)` m |
| vocals | `(3.73, 2.87, 1.50)` m |
| drums | `(3.73, 4.86, 1.50)` m |
| bass | `(1.41, 3.88, 1.50)` m |
| other | `(6.09, 3.89, 1.50)` m |
| 생성 수 | 4개 잔향 조건 × 4개 음원 위치 = 16개 RIR |
| 반사·감쇠 | image-source method와 후기 diffuse 모델, 25 dB부터 diffuse, 60 dB까지 생성 |
| 계산 설정 | 음속 343 m/s, LUT 켬, mixed precision 끔, 생성 RIR 정규화 없음 |
| 채널 적용 | 같은 음원의 L/R에 **동일한 mono RIR** 적용 |

방 높이와 모든 음원의 높이는 기존 승인 기록에 따른 가정이다. x/y 배치는 중간보고서 도식을 바탕으로 정한 값이다. 이 설정은 스테레오 마이크 두 개를 둔 녹음과 다르다. 원곡의 L/R 패닝은 남아 있으나 추가 RIR이 만드는 마이크 간 시간차·위상차는 없다. [gpuRIR 논문](https://arxiv.org/abs/1810.11359)

| 조건 | 생성기에 넣은 목표 T60 s | RIR에서 측정한 평균 T30 기반 T60 추정 s |
|---|---:|---:|
| R1 | 0.260 | 0.223 |
| R2 | 0.890 | 0.921 |
| R3 | 1.280 | 1.356 |
| R4 | 1.960 | 2.078 |

T30은 감쇠 곡선의 −5~−35 dB 구간 기울기에서 60 dB 감쇠 시간을 외삽하는 방식이다. 따라서 0.223초를 “30 dB까지 감쇠하는 데 걸린 시간”으로 읽으면 안 된다. 생성기의 목표값과 실제 RIR 측정값을 두 열로 유지한다. 현재 선택된 모델 평균 방법에는 T60이 입력되지 않는다.

전체 convolution 결과 중 원래 길이 N만 유지하고 음원별 RMS를 복원한다. 이 설계는 악기 균형을 통제하지만 공간의 실제 거리 감쇠까지 재현하지 않는다. 앞 구간 문맥 없이 crop에 RIR을 적용하고 뒤 꼬리를 자르는 경계 효과도 있다. 새 실험에서는 충분한 앞뒤 문맥을 포함해 convolution한 뒤 평가 중앙 구간을 자르는 방식을 별도로 비교할 수 있다. 완료된 실험의 설정은 변경하지 않는다.

## 3 모델과 추론 설정

기준 모델은 HTDemucs `955717e8`이다. CUDA, FP32, batch 1, shifts 0, split 사용, segment 7.0초, overlap 0.25로 고정했다. 공식 Demucs 전후 평균·표준편차 정규화 경로를 적용한다. donor 재분리도 같은 wrapper를 사용한다.

| ID | 실제 checkpoint | 개발 비교 |
|---|---|---|
| htdemucs | `955717e8` | 기준·donor 재분리 |
| msst_bsroformer_ep17 | `model_bs_roformer_ep_17_sdr_9.6568.ckpt` | 단독 교체·HTDemucs와 평균 |
| msst_scnet_small | `scnet_checkpoint_musdb18.ckpt` | 동일 |
| msst_scnet_large_starrytong | `SCNet-large_starrytong_fixed.ckpt` | 동일 |
| msst_scnet_large_9_3244 | `model_scnet_sdr_9.3244.ckpt` | 동일 |
| msst_scnet_xl_ep54 | `model_scnet_ep_54_sdr_9.8051.ckpt` | 동일 |

MSST 소스는 `f17924dd`에 고정했다. small은 batch 4, 나머지 MSST 모델은 batch 2, FP32다. 실제 모델별 config와 normalization, chunk·overlap 설정은 등록 manifest에 따른다. **후처리 공통 STFT 4096을 모델 자체 STFT로 간주하지 않는다.** 모델의 내부 설정은 checkpoint와 함께 제공된 config를 따른다.

BS-RoFormer ep17은 배포표상 MUSDB train 100곡 학습 모델이다. 개별 곡까지 확인한 것은 아니다. HTDemucs 추가 학습곡의 전체 명단도 확인되지 않았다. 모델 구조 논문의 학습 조건이 모든 제3자 배포 checkpoint를 보증하지 않는다.

## 4 후처리 STFT

| 항목 | 값·의미 |
|---|---|
| 창 | periodic Hann 4096 samples, 약 92.9 ms |
| hop | 1024 samples, 약 23.2 ms |
| 주파수 간격 | 약 10.77 Hz |
| 경계 | `boundary=zeros`, `padded=True` |
| 스케일 | `scaling=spectrum` |
| 역변환 | 같은 창·hop, 길이를 N으로 맞춤 |

T1·T2·T5·C1·C2가 이 공통 변환을 사용한다. 채널별 scalar mask와 C1의 채널 간 공분산 처리는 별개다.

## 5 평가 지표

좌우 채널을 이어 붙인 벡터를 사용한다. 평균 제거는 하지 않는다. 정답 `s`, 추정 `z`에 대해 `a = <z,s>/||s||²`, 목표 성분은 `a s`다.

| 지표 | 현재 계산과 읽는 법 |
|---|---|
| SI-SDR | `10 log10(||a s||² / ||z-a s||²)`. 전체 파형 오차. 전역 크기 차이에 불변 |
| target gain | `a`. 정답 방향의 신호가 얼마나 남았는지. 작은 값이 곧 모든 주파수의 소실을 뜻하지는 않음 |
| SI-SIR | 네 정답 stem 공간으로 투영한 `p`에서 `a s`를 제외한 성분을 간섭으로 계산 |
| SI-SAR | `p`와 투영 밖 잔차 `z-p`의 에너지 비. 청취상 모든 왜곡을 설명하는 지표는 아님 |
| SD-SDR | 현재 코드의 `10 log10(||a s||² / ||z-s||²)`. 출력 이득 변화에 민감한 보조 지표 |
| bass collapse | bass target gain <0.1인 곡·잔향 조건 수. 명칭은 본 실험의 조작적 정의 |

SI-SDR, SI-SIR, SI-SAR은 오류의 서로 다른 측면을 보여준다. SI-SAR의 분자 등 세부 정의는 논문·구현마다 다를 수 있으므로 현 코드의 식을 적어 둔다. BSS Eval SDR과 같은 이름으로 바꾸어 보고하지 않는다. [Le Roux et al., 2019](https://arxiv.org/abs/1811.02508)

## 6 집계와 선택

1. 같은 곡·조건·음원의 `후 − 전` 차이를 계산한다.
2. 곡·조건마다 정의된 네 음원의 차이를 평균한다. 개발 세트에서 정답이 무음인 4개 vocals 관측은 모든 후보에서 동일하게 제외됐다.
3. 곡×조건 값의 중앙값을 주 효과로 보고한다.
4. bootstrap는 곡을 10,000회 재표집하고 각 곡의 네 조건을 함께 유지한다. seed는 20261108이다.
5. 개발 채택 조건은 ΔSI-SDR ≥0.2 dB, 같은 효과의 CI 하한 >0, 모든 음원의 중앙값 ΔSI-SAR ≥−0.5 dB다.
6. 통과 후보 중 개발 효과가 가장 큰 방법 하나를 고정했다. 평가 40곡에는 그 방법만 비교했다.

현재 평가의 640개 음원 관측은 640개의 독립 곡이 아니다. 통계 단위는 곡이다. 이번 조건의 유의한 효과와 새로운 곡·방에서의 일반화는 구분한다.
