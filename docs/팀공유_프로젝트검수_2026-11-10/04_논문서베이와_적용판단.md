# 논문 서베이와 적용 판단

## 1 조사 범위와 결론

기존 조사에 포함된 **96개 문헌 카드의 제목·방법·관련성 기록을 다시 검토**하고, 현재 결과 해석에 필요한 논문 원문·저자 페이지·공식 소프트웨어 자료를 재조회했다. 2026년의 음악 후처리·반복 분리·음원 복원 연구도 보완했다. 검색 기준일은 2026-11-10이다. 기존 96편을 이번에 모두 원문 전체 정독하거나 재현했다는 뜻은 아니다.

기존 카드의 확인 수준은 전체 본문 59, 본문 일부 1, 초록 32, 서지 4였다. 이는 **이전 조사 기록**이다. 전체 목록 CSV에는 이 수준과 기존 방법 요약을 보존했다. 아래 표의 확인 수준은 이번 재조회 범위다. 신규·보충 연구는 별도 표에 적었다. 유료 본문이나 전체 실험표를 확보하지 못한 연구에서 구체적인 개선 수치를 채택하지 않았다.

**지금 적합한 방향은 모델 결합 결과의 검증을 마무리하고, 필요하면 잔향 조건에 맞춘 학습으로 확장하는 것이다.** C1을 먼저 권했던 11월 8일 서베이의 우선순위는 현재 실험 결과에 맞춰 바뀌어야 한다. MWF는 근거 있는 비교 방법이었지만 이번 구현에서는 악화됐고, 두 모델 평균은 평가까지 개선을 보였다.

## 2 분리 모델은 무엇이 다른가

| 연구 | 사용한 방식 | 우리 상황에서의 의미 | 이번 확인 |
|---|---|---|---|
| [Hybrid Demucs, Défossez, 2021](https://arxiv.org/abs/2111.03600) | 파형과 spectrogram 경로를 결합 | 기존 파형 출력을 단순 magnitude mask로 바꾸면 기존 장점을 잃을 수 있음. 최신 HTDemucs 사후 MWF의 성능을 직접 증명하는 논문은 아님 | 기존 본문 카드 검토 |
| [HTDemucs, Rouard et al., ICASSP 2023](https://arxiv.org/abs/2211.08553) | 파형·주파수 경로 사이 self/cross-attention, 추가 데이터·음원별 fine-tuning | 현재 기준. 논문 최고 수치와 우리가 사용한 `955717e8`의 설정을 동일시하지 않음 | 본문 일부 재확인 |
| [KUIELab-MDX-Net, Kim et al., 2021](https://arxiv.org/abs/2111.12203) | 시간·주파수 두 모델의 분리 결과 결합 | 모델 결합은 기존 연구 흐름. 데모의 Inst HQ3 2-source 파일이 원 논문의 전체 시스템과 같다는 근거는 없음 | 초록·원문 랜딩 재확인 |
| [Open-Unmix, Stöter et al., 2019](https://joss.theoj.org/papers/10.21105/joss.01667) | 음원별 magnitude 예측 후 다채널 Wiener 복원 | MWF의 표준적인 사용 맥락. HTDemucs 최종 파형에 다시 적용하는 것과 출발점이 다름 | 공식 논문·구현 설명 재확인 |
| [BSRNN, Luo·Yu, 2023](https://arxiv.org/abs/2209.15174) | 주파수 대역을 나누고 대역·시간 축 RNN을 교대로 적용 | 저역을 세밀하게 처리하는 구조적 동기. 저역을 단순히 bass로 옮기는 규칙과 다름 | 원문 방법 발췌 재확인 |
| [BS-RoFormer, Lu et al., ICASSP 2024](https://arxiv.org/abs/2309.02612) | 불균등 band-split, 시간·대역 Transformer, RoPE, 복소 마스크 | 현재 ep17과 HTDemucs 결합의 직접 구성요소. 자체 모델 교체와 결합을 각각 비교한 것이 적절 | 본문 방법·손실 재확인 |
| [Mel-Band RoFormer, Wang et al., 2023](https://arxiv.org/abs/2310.01809) | 겹치는 mel 대역으로 표현, 겹친 출력의 마스크 결합 | 모든 stem에 더 좋은 것은 아님. 원문 표에서 bass는 BS-RoFormer보다 낮음. vocals용 공개 모델을 4-source 모델로 취급하지 않음 | 본문·표 1 재확인 |
| [SCNet, Tong et al., ICASSP 2024](https://arxiv.org/abs/2401.13276) | 저·중·고 대역의 서로 다른 압축률과 분리 네트워크 | 속도와 품질 비교 후보. 현재 small+HTDemucs는 개발에서 +1.074 dB, 추론 비용이 BS-RoFormer 결합보다 작음 | 본문 구조 재확인 |

논문의 표준 MUSDB SDR과 우리 30초·추가 RIR·SI-SDR 변화량은 같은 지표가 아니다. “논문에서 더 높다”는 이유만으로 현재 잔향 조건에서도 더 높다고 예측하지 않는다.

## 3 학습 없는 후처리와 반복 처리

| 연구 | 사용한 방식 | 적용 판단 | 이번 확인 |
|---|---|---|---|

| [OR-PIT, Takahashi et al., Interspeech 2019](https://www.isca-archive.org/interspeech_2019/takahashi19_interspeech.html) | 한 화자와 나머지를 나누도록 학습하고 재귀 적용 | 반복에 맞춘 **학습**이 있음. 고정 HTDemucs donor 재분리의 실증 근거로는 간접적 | 공식 초록 재확인 |
| [Lebart et al., 2001](https://www.ee.columbia.edu/~dpwe/papers/LebBD01-ssdereverv.pdf) | 후기 잔향의 지수 감쇠 PSD 추정과 spectral subtraction | 원 목적은 음성 dereverberation. 현재 T4의 잔향 재배분과 목적·출력이 다름 | 본문 방법·한계 발췌 확인 |
| [norbert 공식 구현](https://sigsep.github.io/norbert/) | magnitude 초기화와 다채널 EM Wiener 추정 | 현 코드의 실제 API·버전·초기화 기록이 중요. EM=0은 공간 모형을 충분히 갱신한 결과가 아님 | 기존 공식 구현 검토 + 현재 로컬 호출 대조 |

이번 결과에서 단순 mask의 부진은 magnitude뿐 아니라 phase 대체 손실도 관련될 수 있다. 정답 magnitude를 넣은 진단과 정답 phase를 넣은 진단이 모두 개선됐다. 이 둘의 상대적인 기여율을 현재 수치만으로 분해해 확정할 수는 없다.

PaRIRset 연구의 SCNet 학습은 L40S 한 장에서 모델당 약 7일로 보고됐다. 이는 **그 논문의 학습 비용**이며 GTX 1660의 시간으로 환산하지 않는다. 현재 프로젝트의 3시간대 실행은 사전학습 모델 추론·후처리·평가이고, 신경망 학습 시간이 아니다.

## 6 초기 잔향 제어 과제와 연결되는 문헌

[De Man·McNally·Reiss, JAES 2017](https://doi.org/10.17743/jaes.2016.0062)은 멀티트랙 믹스에서 상대 잔향 음량과 감쇠 특성이 지각에 미치는 영향을 분석했다. “잔향이 많을수록 좋다”가 아니라 허용 범위와 지각 판단이 곡·믹스에 따라 달라진다는 근거다. 최초 DOCX의 잔향 배분·청취 과제를 계속할 때 중요하다. 저자 원문의 방법·결론을 재확인했다.

[Koo·Paik·Lee, ICASSP 2021](https://arxiv.org/abs/2103.02147)은 입력 보컬의 내용과 참고 보컬의 잔향 특성을 결합하는 신경망을 사용했다. 단순 RIR 추가 및 현재 wet stem 분리와 다르다. 참조 없는 일반 음악 잔향 제거기로 동일시하지 않는다. 원문 방법·평가 발췌를 확인했다.

두 연구는 현재 모델 결합의 SI-SDR 개선을 입증하는 근거가 아니다. **최초 잔향 제어 응용을 다시 주과제로 삼는다면, 별도 청취 평가 설계가 필요하다.**

## 7 지표와 데이터 문헌

[Le Roux et al., ICASSP 2019](https://arxiv.org/abs/1811.02508)은 허용 필터가 있는 SDR과 SI-SDR/SD-SDR의 차이를 설명한다. 현재처럼 scale 손실이 중요한 경우 SI-SDR만 보고 bass 복원을 판단하지 않고 target gain과 SD-SDR을 함께 보는 근거다.

[MUSDB 공식 문서](https://sigsep.github.io/datasets/musdb.html)는 100 train/50 test, 44.1 kHz stereo와 알려진 stem 오류를 제공한다. `Detsky Sad - Walkie Talkie`의 drums에는 other 누출이, `PR - Oh No`에는 원 mixture 합성 관련 오류가 알려져 있다. 현재 혼합을 stem 합으로 재생성하므로 후자의 원 mixture 오류를 그대로 입력하는 것은 아니지만, 음원 라벨의 의미적 오류까지 제거되는 것은 아니다. 불리한 곡을 사후 삭제하는 근거로 사용하지 말고 사례 해석에 명시한다.

## 8 팀에 권하는 읽기 순서

1. 실험 담당: 현재 설정 문서 → HTDemucs → BS-RoFormer → 현재 모델 평균 결과.
2. 오류 분석 담당: SI-SDR 원문 → MWF 음악 논문 → 정답 magnitude/phase 진단.
3. 다음 연구 담당: CrowdioSet/PaRIRset → MSG → 학습형 MIMO. 데이터와 GPU 시간을 먼저 확인.
