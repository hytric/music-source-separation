# 잔향 성분 대조 결과

개발 10곡에서 지연만·초기 50 ms·전체 RIR·gain 대조를 실제 실행했다. 새 추론은 60개, 전처리·채점 포함 149.7초였다.

bass의 곡별 대응 SI-SDR 변화는 지연만−원본 +0.020 dB, 초기 R4−지연 −4.326 dB, 전체 R4−초기 −6.399 dB다. 초기 R4는 소실 1/10, 전체 R4는 4/10이었다. 입력과 정답을 바꾸는 진단이므로 새 후처리 성능 개선은 아니다.

후기 부분을 포함하면 추가 손실이 관측됐고 초기 반사 영향도 남았다. gain 고정 대조에서도 같은 방향이었다. 개발 10곡의 탐색 결과이며 모든 공간에 일반화하지 않는다.
