# 추가 잔향 영향 분석

[통합 보고서](공유본.html) 또는 [Markdown 보고서](결과보고서.md)를 읽으세요.

동일 50곡의 추가 잔향 없는 HTDemucs 분리를 새로 실행하고 기존 잔향 4조건과 비교했습니다. 핵심은 bass·drums의 성분 손실과 other의 간섭 증가입니다. 50곡 원본에는 bass 소실이 없었고, 잔향 200조건 중 41조건에서 새 소실이 관측됐습니다. 세부 물리 원인이 후기 잔향인지 초기 반사·색채·지연인지는 아직 분리하지 않았습니다.

- `조건별_음원별_성능.csv`: 조건/음원/분할별 수치
- `원본대비_곡별_변화.csv`: 같은 곡의 차이와 순서 대조
- `5초구간별_변화.csv`: 오류가 큰 구간
- `주파수대별_변화.csv`: 주파수대별 진단
- `분석요약.json`: 전체 수치와 검증
- `실험설정.md`: 계산 전 설정 및 실행 보완 기록

추가된 5초 사례는 정량·스펙트럼 분석입니다. 청취 평가를 수행했다고 주장하지 않습니다. 원곡과 모델 파일은 이 공유 묶음에 포함하지 않습니다.
