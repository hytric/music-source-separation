# 잔향 성분 대조 사전 기록

사용자 요청: 실험 진행 결과를 Notion 오늘할일 프로젝트 세부 결과로 정리. 서베이와 해볼 실험 정리 후 실제 실행·결과 보고.

현재 상태: 원본50곡과잔향200조건진단 완료. 지금 추가로 실행하는 것은 개발10곡의 물리 성분 대조이며 새후처리/학습 아님.

기준: MUSDB18-HQ 기존dev10곡 중앙30초, HTDemucs955717e8,FP32,shifts0,segment7s,overlap.25,동일공식정규화. 기존코드/결과/평가40수정없음.

조건:
D0=추가RIR없음(기존새분리cache).
D1=음원별기하학적전파지연만. 각 h는 direct_delay_samples 위치의 단위임펄스. 각stem원본RMS복원. 위치동일이므로10곡만추론.
E1~4=각RIR의직접도달시각+50ms까지유지,다음5ms cosinefade후0. 같은채널처리/원길이crop/각stemRMS복원. 10곡×4조건새추론.
F1~4=전체RIR의기존wet출력재사용.
E4-fixedgain=E4를전체R4데이터생성gain으로처리,early출력자체RMS로재정규화안함.10곡새추론. 초기구간절단과정규화의결합효과확인용.

각조건은그조건에맞게만든정답stem으로평가. D0/D1/E/F의서로다른target정의를명시하며출력품질을동일target상의새후처리개선으로주장하지않음. 50ms는본탐색의사전고정컷오프이며음향학적으로보편적인초기/후기경계가아님.

지표: 기존projection SI-SDR/SIR/SAR/SD-SDR,target gain,출력RMS,음원간투영계수. 같은곡차이중앙값,개발곡10cluster bootstrap CI를탐색적으로보고. bass gain<.1 판정과출력/정답RMS<.1를구별. 성공을보장하거나컷오프를결과에맞춰고르지않음.

검증: unit impulse의원신호복원,지연샘플위치,fade의보존/0종료,기존F4정답재합성,그기존F4지표와일치 확인. GPU전후오류점검. 새cache는 /home/iiplab/code/music-source-separation/.agent_runtime/rir-components-20261110/.

기대계산: 새GPU추론60개 약2분의warmforward추정,전체전처리·채점·검수 포함약3~8분(예상,측정아님). 신경망학습없음. 결과는로컬새폴더와Notion세부작업에기록.
