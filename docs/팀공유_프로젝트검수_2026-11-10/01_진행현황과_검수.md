# 진행 현황과 검수

## 1 현재 판단

**기초 학습과 구현은 충분히 진행됐고, 재현 가능한 비교 실험도 확보했다. 연구 주장과 최종 평가 범위를 정리할 단계다.** 단순 마스크의 작은 개선을 확대해 설명할 필요가 없다. 최신 실험에서 더 분명한 성과인 모델 결합 결과가 나왔고, 기존 후처리가 실패하는 조건도 설명할 자료가 생겼다.

현재 실험 결과는 고정 HTDemucs의 후처리 개선과 다른 모델을 함께 사용하는 개선을 나누어 제시해야 한다. 최종 채택된 방법은 두 분리기를 각각 실행해 파형을 평균하므로 두 번째 범주다.

## 3 최신 결과

현재 실험은 30초 구간, 개발 10곡×4조건, 평가 40곡×4조건이다. 변화량은 같은 곡·조건에서 후처리 또는 모델 결합 결과에서 HTDemucs 결과를 뺀 값이다.

| 개발 세트 방법 | ΔSI-SDR 중앙값 dB | 판단 |
|---|---:|---|
| 균등 mixture consistency | +0.028 | 변화가 작음 |
| 비율 마스크 α=1 / α=2 | −0.450 / −1.174 | 악화 |
| 원 출력 75% + α=1 마스크 출력 25% | +0.030 | 변화가 작음 |
| MISI 유사 반복 1회 / 2회 | +0.008 / +0.010 | 변화가 작음 |
| 다채널 Wiener 0회 / 1회 | −0.450 / −3.456 | 현재 설정에서 악화 |
| 다채널 Wiener 2회 | 채택 제외 | 기준 지표가 정의된 관측 중 1개에서 후보 지표가 미정의 |
| other 재분리 후 bass 이전 | +0.001 | 현재 설정에서 개선 근거 부족 |
| drums 재분리 후 bass 이전 | 약 +0.000009 | 현재 설정에서 개선 근거 부족 |
| BS-RoFormer 단독 교체 | +0.544 | 결합보다 작은 개발 효과 |
| HTDemucs + BS-RoFormer 평균 | **+1.157** | 사전 채택 기준 통과, 평가 대상 선정 |
| HTDemucs + SCNet small 평균 | +1.074 | 개발에서 유망, 해당 평가 세트에서는 미검증 |
| HTDemucs + SCNet large 2종 평균 | +0.849 / +1.084 | 개발 결과 |
| HTDemucs + SCNet XL 평균 | +0.691 | 개발 결과. 모델 크기만으로 우열을 정할 수 없음 |

21개는 identity를 제외한 실용 후보 수다. identity까지 포함한 실행 등록은 22개다. 전체 후보 수치는 CSV에 있다. 개발 세트 Holm 보정 p값으로는 선정된 평균 방법도 약 0.101이며, **개발 다중검정의 유의한 승리라고 표현하지 않는다.** 기존 선택 규칙은 효과 크기·곡 단위 bootstrap 신뢰구간·음원별 SAR 하한을 사용했고, Holm p값은 보조 보고였다.

| 평가 40곡 결과 | 값 |
|---|---:|
| 선택 방법 | HTDemucs와 BS-RoFormer ep17의 파형 50:50 평균 |
| 전체 ΔSI-SDR | **+1.652 dB** |
| 곡 단위 cluster bootstrap 95% CI | **[+1.518, +2.000] dB** |
| 곡별 평균 차이 Wilcoxon 양측 p | 3.57×10⁻⁸ |
| vocals / drums / bass / other ΔSI-SDR | +1.565 / +1.640 / +1.709 / +1.400 dB |
| 4개 음원 평균이 좋아진 곡·조건 | 153/160 |
| 개별 음원 SI-SDR이 좋아진 비율 | 587/640, 91.7% |
| bass target gain <0.1 | 31/160 → 12/160 |

**개선 비율 91.7%와 153/160은 서로 다른 집계다.** 전자는 음원 단위, 후자는 네 음원 평균 단위다. 신뢰구간은 곡을 재표집하여 같은 곡의 네 잔향 조건을 함께 유지했다.

평균 개선이 모든 곡의 개선을 뜻하지 않는다. 예를 들어 `PR - Happy Daze / R2`의 vocals SI-SDR은 −21.56→−43.38 dB로 악화됐다. 기준 자체가 낮고 투영 이득이 매우 작을 수 있으므로 파형·활성 구간을 함께 확인해야 한다. 평가 사례를 보고 새 가중치를 맞춘 뒤 같은 평가 세트의 성능을 새 검증 결과로 제시해서는 안 된다.

## 4 잘된 점

1. 정답을 잔향이 포함된 같은 채널의 stem으로 고정했다. 분리와 잔향 제거를 혼동하지 않았다.
2. 곡 단위 개발·평가 분리와 후보·임계값 고정, 파일 해시, 선택 기록, 중복 평가 방지가 있다.
3. 불리한 결과와 미정의 지표를 보존했다. 후보 1개를 무효 처리하고 좋은 관측만 골라 채택하지 않았다.
4. 실제 모델 파일·설정·소스 버전과 추론 비용을 확인했다. 데모 코드와 연구 코드도 분리했다.
5. 정답 magnitude·phase를 바꾸는 진단으로 단순 마스크 실패 원인을 나누어 볼 수 있다.

## 5 우선 수정할 설명과 한계

| 중요도 | 항목 | 피드백 |
|---|---|---|
| 높음 | 현재 중단 지점 | 계산 중단 문서만 읽으면 상태가 틀린다. 최신 계산·통계 산출은 완료. 남은 것은 결과 검수 마무리·청취·해석·발표 자료 |
| 높음 | 연구 기여 | 채택 결과는 모델 앙상블이다. 이를 RT60 적응형 spectral masking의 성공으로 쓰지 않는다 |
| 높음 | 데이터 변경 | OpenAIR, 대체 실측 RIR, gpuRIR을 구분한다. 기존 +0.06 dB와 최신 +1.652 dB를 같은 조건의 개선 전후로 연결하지 않는다 |
| 높음 | 평가 노출 | 평가 40곡은 과거 오류 분석에 노출됨. 이번 실행의 사전 고정은 장점이지만 과거 노출을 없애지는 못함 |
| 높음 | 공간 일반화 | R1~R4는 같은 크기·배치에서 흡수 조건을 바꾼 4조건. 서로 독립된 네 실제 방이 아님 |
| 높음 | 학습 데이터 | HTDemucs 추가 800곡의 곡별 중복 감사는 미확인. BS-RoFormer 배포표의 train-only 선언과 실제 곡별 확인을 구별 |
| 중간 | 재현성 코드 공백 | 의존 모델 config·commit·batch 등의 완전한 추론 정보가 선택 잠금에 모두 묶이지 않음. 이번 실행은 외부 해시 대조로 완화했지만 코드 결함이 수정된 것은 아님 |
| 중간 | mixture residual | 평가 JSON에는 선택 출력의 잔차만 저장. 기준 대비 감소·증가는 현재 기록만으로 주장할 수 없음 |
| 중간 | 통계 문구 | 미정의 후보 제외 후 실제 Holm family는 20개. 사전 문서의 21개와 차이를 공개. 선택 결과 자체는 효과·CI·SAR 기준으로 재현됨 |
| 중간 | 청취·표준 SDR | 정식 청취와 BSS Eval 비교는 완료 근거 없음. SI-SAR 상승을 사람이 느낀 자연스러움 향상으로 바꾸어 쓰지 않음 |

이번에 코드 검수 기록에서 확인한 잠금 공백은 향후 새 실험 버전에서 수정할 항목이다. 완료된 평가 중간에 코드를 바꾸어 동일한 실험으로 취급하지 않는다.

## 6 발표에 사용할 수 있는 문장

> MUSDB18-HQ의 30초 구간에 음원별 합성 RIR을 적용하여, 잔향이 포함된 정답 stem에 대한 분리 성능을 분석했다. 단순 마스크·일관성 보정은 개발 세트에서 개선이 작거나 성능을 낮췄다. 개발 세트에서 선택한 HTDemucs와 BS-RoFormer의 동일 가중치 결합은 평가 40곡·160조건에서 SI-SDR 변화량 중앙값 +1.65 dB를 보였다. 다만 평가 곡의 과거 분석 노출과 학습 데이터의 곡별 중복 확인 한계가 있고, 새로운 공간 및 청취 평가를 통한 검증은 남아 있다.

권장 제목: **합성 잔향 조건의 음악 음원 분리 오류 분석과 사전학습 모델 결합 평가**. 현재 결과를 반영하는 제안이며 기존 제출 제목을 변경한 것은 아니다.
