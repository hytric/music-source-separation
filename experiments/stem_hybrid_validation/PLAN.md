# 음원별 고정 결합 평가 계획

2026-11-14 · 결합 결과를 계산하기 전에 고정

기존 앙상블 B=(HTDemucs+BS-RoFormer)/2와 미세조정 SCNet F의 저장된40초 출력을 사용한다. H의 vocals/other는B, drums/bass는F로 고정한다. F는이미선택된step1000이며이번에선택을다시최적화하지않는다. 같은 validation10곡의dry/wet_R4,40초입력·중앙30초·원래잔향정답을유지한다. 음원·정답·checkpoint·각예측·코드의SHA를확인하고실제파형을결합해지표를재계산한다. 새학습·GPU추론·confirmation사용은없다.

주요 검정은 기존 앙상블 대비 wet의 곡별 유효4음원 평균 SI-SDR 대응 차이 중앙값이다. +0.2dB 이상이면서10,000회 곡bootstrap95%CI하한>0이어야한다. dry전체,wet vocals/other의CI하한≥−0.2dB와새bass소실0도모두만족해야고정결합을통과로판정한다. bass소실은target_gain<0.1로기존정의를유지한다. 무음정답은제외하고분모를표시한다. 원래정한방법이실패하면다른후보로주검정을바꾸지않는다.

보호 음원은 B와 비트 단위로 같아야 한다. H의 각 음원 지표가 제공 모델의 해당 지표와 일치하는지20조건 모두 확인한다. B/F 재계산도 저장된 이전 지표와 대조한다. 음원합 잔차의 RMS/입력RMS 및최대절대오차를B/F/H에대해함께보고한다. 서로다른모델의출력을결합하면각음원지표가좋아도중복성분·누락성분이생길수있으므로입력복원이나청감향상을그지표만으로단정하지않는다. 잔차재배분·출력합강제보정은vocals보호를바꾸므로이번에적용하지않는다.

고정결합의dry문제가능성을진단하기위해조건라벨분기(B on dry/H on wet)와곡전체단위GT oracle(B/H중정답대비4음원평균SI-SDR가좋은쪽,동률은B)을함께계산한다. 둘다정답정보가있는진단대조이며실사용추론성능으로표현하지않는다. oracle상한은이두후보중곡전체선택단위에만해당하며모든선택방식의절대상한이아니다. 실제정답없는선택기는이번범위에서학습하지않는다.

[SCNet 미세조정 결과](../scnet_finetune/결과/결과보고서.md)의음원별상보성과step1000출력을가져왔다. [공식 모델 비교](../parirset_validation/결과/결과보고서.md)와[입력전처리검증](../frontend_validation/결과/결과보고서.md)의입력합성·HTDemucs/BS-RoFormer cache를재사용한다. 이번새결과는고정결합의효과·dry보호·복원합오차이며이전학습과다른실험이다. validation은이미노출됐고공개백본사전학습중복가능성도남아독립일반화검증이아니다.
