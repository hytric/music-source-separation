# QG1 GPU 실험 실행 기록

2026-11-15 실행 시작. **teacher cache 생성 작업을 실제 GPU에서 시작했다.** 전체QG1 학습·평가완료를뜻하지않는다.

처음에는GPUfree약2.41GiB여서과거SCNet reserved1.283GiB+1GiB의모델별조건으로F8개를FP32/40초그대로실행했다. 최대예약1.283GiB,평균약4.43초/조건으로완료했다. 이어BSR의2GiB allocator상한시험은OOM으로중단했고그출력은완료cache로쓰지않는다.

그사이다른GPU작업의메모리가해제돼free약5.30GiB가확인됐다. 원래strict4GiB조건으로새runtime `quality-gate-v1-full`을만들고8입력준비→BSR/HTD/F 각각8조건smoke→전체320입력→F/HTD/BSR 각각320조건의순차작업을시작했다. 각모델은별도프로세스다. 실패·자원부족이면후속단계를멈추며자동재시도하지않는다. smoke24출력은총960출력에포함한다.

실행controller는해당runtime의job.py이며job-status.json이현재단계,각stage.log가실제추론기록이다. teacher준비가모두끝나도표시는teacher_cache_complete이고선택기fit/validation완료로표시하지않는다. labels/fit/calibrate/freeze/evaluate/report의CLI통합은아직후속구현이다.

모델입력길이·정규화·FP32·체크포인트·source순서·threshold설계는바꾸지않았다. 바뀐것은새run으로기록한자원실행정책이며기존실험의성능판정을재해석하지않는다. 기존GPU작업을종료하는명령은실행하지않았다.

이전에추정한teacher3.16시간은공유부하/I/O를제외한기준이며실제모델별smoke후갱신한다. GPU작업이돌고있다는것과성능개선이확인됐다는것을구분한다. 자동최종보고/이세션자동재호출은보장하지않으며다음상태요청에서실제파일을읽어보고한다.

세 모델 GPU smoke 각8/8, 총24/24 완료. 현재전체320입력을준비중이며순차controller가살아있음을확인했다.

| 모델 | 완료 | 조건당시간중앙값 | 최대예약GiB |
|---|---|---|---|
| finetuned_scnet | 8 | 2.212초 | 1.283 |
| htdemucs | 8 | 2.246초 | 0.863 |
| msst_bsroformer_ep17 | 8 | 29.435초 | 2.395 |

이24개는새strict실행의유효smoke이며이전SCNet자원시험8개와실패한BSR상한시험을합산하지않는다. 전체예상960개에포함된다. 현재실측속도단순환산으로teacher단계는약3~4시간+전처리/I/O/자원변동을예상하지만확정완료시각은아니다. 전체QG1학습/평가종료시간이아니다.

총단계는job-status.json,실제teacher개수는모델별complete.json/모델status에서확인한다. prepare단계의legacy teacher_outputs=0필드는기존teacher수를집계하지않는단계로컬값이므로전체진행률로사용하지않는다. 후속구현에서이필드를교정해야한다.
