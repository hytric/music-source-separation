# 입력 시간 전처리와 잔향 재배분 검증

2026년 11월 13일 · 실행 전 고정

WPE 입력 전처리가 고정 HTDemucs 분리를 돕는지, 제거한 성분의 재배분이 원래 잔향 정답을 유지하는 데 도움이 되는지 검증한다. 이전 EQ 실험의 분리기 입력 길이와 다르므로 기존 숫자를 그대로 재사용하지 않고, 같은 입력 길이에서 EQ를 다시 비교한다.

준비된 validation10곡의 중앙30초와 원래 R4 음원별RIR을 사용한다. 좌우같은음원RIR·음원별RMS복원은기존규칙이다. 앞뒤5초guard를추가한40초를모든조건의모델입력으로사용하고, 같은중앙30초를평가한다. wet의guard에는실제convolution꼬리를포함한다. 입력/정답길이·정렬·합성일치를먼저검사한다. 최종confirmation과학습checkpoint는사용하지않는다.

| 출력 | 의미 |
|---|---|
| raw | 원래 입력의 고정 분리 |
| raw_weighted | 같은 weighted residual 배분만 적용한 대조 |
| eq | 입력 EQ → 고정 분리 → 역EQ |
| wpe | WPE 입력 → 고정 분리 |
| wpe_uniform | WPE 분리 뒤 원래 혼합 잔차를 균등 배분 |
| wpe_weighted | WPE 분리 뒤 최근 음원 power를 이용해 원래 혼합 잔차 배분 |

배분은 복소 STFT에서 `Z_k + mask_k*(X-sum(Z))`다. mask는 해당 분리 출력의 power를0.2초causal smoothing하고음원합으로정규화한다. 무음bin에서는1/4이다. 원래mix의잔향을돌려주되정답의정보는배분에사용하지않는다. 이것은원음원별RIR의정확한복원이라고보장하지않는다.

NARA WPE0.0.11 공식 NumPy 구현, taps10·delay3·3회 반복, FFT4096·hop1024를 고정한다. 음악의지속음이나직접음을손상할수있으므로dry조건손상·bass target gain·RMS·새소실을함께본다. WPE는주로후기잔향을다뤄초기반사문제전체를해결한다고가정하지않는다. 별도vendor로설치해기존환경을바꾸지않는다.

주요후보는WPE+weighted이고wet4stem평균ΔSI-SDR중앙값≥+0.2dB및곡bootstrap95%CI하한>0을기본개선기준으로한다. raw_weighted 대비차이로입력전처리의추가가치를확인한다. 각음원과dry손상을따로보고bass소실전이를기록한다. 여러후처리중가장좋은것만사후선택해성공으로보고하지않는다. 10곡의탐색결과이며학습중복감사가미확인이다.

20곡조건×4종류의분리입력=80GPU호출이다. 기타출력은같은결과에서계산한다. 설정·패키지·코드·모델·입력hash를고정하고pilot은수치검증만사용한다. 안전/수치실패는기록후중단한다. 전처리나경계설정을성능점수에맞춰변경하지않는다.

참고: [NARA WPE 공식 구현](https://github.com/fgnt/nara_wpe), [Convolutive Prediction](https://arxiv.org/html/2108.07376v2). 음성연구의이득을음악이득으로전이하지않으며이번실험에서직접확인한다.

## 전체 실행 전 추가한 음량 대조

최초 pilot 1곡의 수치 검사 후, 성능값에 맞춰 후보를 고르지 않고 gain_weighted 대조를 추가했다. WPE 입력과 같은 RMS가 되도록 원래 혼합에 공통 gain만 곱해 분리하고 같은 weighted 잔차 배분을 적용한다. 이를 통해 시간 전처리의 추가 가치를 검토한다. 주요 후보·WPE·EQ 강도·판정 기준은 유지한다. 최종버전은80GPU호출이고 최초6호출pilot과별도binding으로집계한다.
