# 학습 시작 전 준비 완료 보고서

2026년 11월 11일 · 상태 ready · 실제 학습 업데이트 0회

**실험 기획과 모델·손실·학습/평가 코드를 구현하고 학습 시작 직전까지 준비했다.** 공식 train 전수 검증, 분할된 RIR 생성, 400개 조건의 고정 HTDemucs 출력 생성, 실제 GPU forward/backward와 초기 validation을 완료했다. 가중치는 초기 상태이며 optimizer state는 비어 있다. 이 보고서는 실행 준비의 검증이며 학습 개선 결과가 아니다.

## 준비한 입력과 코드

| 항목 | 확인 결과 |
|---|---|
| 원자료 | 공식 train 100곡·500 WAV, CRC·SHA256·전수 디코딩·유한값 검사 완료 |
| 곡 분할 | 학습 80·validation 10·내부 confirmation 10곡 |
| RIR | 학습 64·validation 16·confirmation 16묶음, 24개 방·384개 파일 |
| cache | 학습 320·validation 40·confirmation 40개, 총 400개 30초 record |
| cache 크기 | 혼합·정답·추정 파형 합계 약 38.10 GB |
| 짧은 원곡 | 6곡. 제외·반복 없이 중앙 정렬 zero padding, 실제 신호 구간에서 학습 crop |
| 모델 | 복소 잔차 공동 보정망 325,024 파라미터 |
| 자동 테스트 | 17개 통과. 분할·변조 거부·STFT·무음·gradient·출력 합·optimizer 경계 등 |
| 기존 평가 지표 대조 | 실제 표본 4개 stem SI-SDR의 기존 함수 대비 최대 차이 1.39e-13 dB |

학습 입력 생성의 실제 경과 시간은 19.91분이다. 데이터 추출·RIR 생성·코드 구현·최종 검증 시간은 별도다. 코드가 모델·데이터 다운로드를 자동으로 실행하지 않으며 기존 test 50곡과 완료 실험의 산출물은 변경하지 않았다.

## 바로 다음 실행

현재 컴퓨터에서 이 폴더를 기준으로 다음 명령을 실행하면 실제 학습을 시작한다. **이번 준비 작업에서는 이 명령을 실행하지 않았다.**

```bash
bash run_local.sh train --start-training --stop-after 100
```

`--start-training` 없이 train을 호출하면 거부하는 것을 확인했다. 100 step은 동일한 3,000 step pilot의 앞부분이다. 이후 저장된 last.pt를 --resume으로 지정해 이어갈 수 있다. 준비 이후 config·코드·입력·환경이 바뀌면 기존 readiness로 시작할 수 없다.

다른 컴퓨터나 GitHub 코드에서는 [README의 경로 인자](README.md)를 사용한다. 현재 컴퓨터용 run_local.sh는 Git에 포함하지 않는다.

## 보존한 실행 근거

새 runtime은 기존 banelp-v1과 분리된 `banelp-refine-v1`이다. 아래 경로는 새 runtime을 `$R`로 표기한다.

- `$R/manifests/dataset.json`: 공식 train, 내용 hash와 곡 분할·crop·padding.
- `$R/manifests/rirs.json`: 공간 분할·geometry·측정·파일 hash.
- `$R/manifests/cache.json`: 합성과 분리기·코드·환경 hash와 400개 입력.
- `$R/readiness.json`: 실제 GPU 수치와 전수 무결성 검사, 시작 조건.
- `$R/initial/step-000000.pt`: 모델·비어 있는 optimizer state·RNG·config·binding.
- `$R/initial/validation-step-000000.json`: 업데이트 없는 초기 validation 40개 행.

## 남은 검증

실제 학습의 메모리·속도·수렴과 validation 개선은 첫 100 step 이후 측정한다. 기초 분리기의 학습곡 중복은 감사되지 않았고, 기존 test는 과거 오류 분석에 노출됐다. 새 곡·새 공간 일반화와 청취 품질은 후속 평가 대상이다. [실험 기획](EXPERIMENT.md)은 비교 기준과 성공 조건의 해석 범위를 정하고, 이번 보고서는 그 설계를 구현해 준비한 실제 범위와 측정값을 추가한다.
