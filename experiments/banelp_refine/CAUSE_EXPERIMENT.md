# 잔향의 주파수 착색 원인 검증과 전후 EQ 대조 실험

2026년 11월 11일 · 추가 실험 설계 · 실행 전

**검증할 가설은 잔향이 바꾼 주파수별 크기 분포가 HTDemucs의 베이스 배정 오류에 기여하며, 그 크기 분포를 분리 전에 보정하면 오류가 줄어든다는 것이다.** 먼저 주파수 크기와 위상 성분을 나눠 원인 기여를 확인한다. 이어서 같은 잔향 입력과 같은 잔향 정답에서 학습 없는 EQ 보정을 검증한다. 결과에 따라 가설을 지지·기각·보류하며, EQ가 좋아졌다는 이유만으로 원인이 설명됐다고 판정하지 않는다.

이 실험은 [기존 학습 실험](EXPERIMENT.md)에 추가하는 별도 설계다. 보정망 학습, 학습 설정 변경, 기존 confirmation 사용은 포함하지 않는다. 현재 준비된 step 0 상태를 유지한다.

## 이 실험이 필요한 이유

기존 [잔향 영향 분석](https://github.com/hytric/music-source-separation/blob/5d604ed/docs/reverberant-music-source-separation-analysis-2026-11-10/07_추가잔향_영향분석.md)은 베이스·드럼 손실과 other의 간섭 증가를 관찰했다. 개발 10곡의 [지연·초기 반사·전체 잔향 대조](https://github.com/hytric/music-source-separation/blob/5d604ed/docs/reverberant-music-source-separation-analysis-2026-11-10/08_잔향성분_대조결과.md)에서는 지연만의 베이스 변화가 +0.020 dB였고, 초기 R4−지연은 −4.326 dB, 전체 R4−초기는 −6.399 dB였다. 이 관찰은 반사를 포함한 조건의 악화를 보여주지만, 초기 RIR을 자르면 주파수 응답도 바뀌므로 시간 길이만의 원인이라고 확정할 수 없다.

이번 설계는 주파수 크기 응답이 같은 조건과 다른 조건을 명시적으로 만든다. 그 뒤 단순 보정의 결과까지 연결해 다음 질문에 답한다.

1. 크기 응답의 변화만으로도 베이스 분리가 나빠지는가.
2. 크기 응답을 유지한 위상 변화에서도 같은 문제가 생기는가.
3. 분리 전 크기 응답 보정이 같은 wet 정답에서 실제 오류를 줄이는가.

신경망 어느 층이 잘못 작동하는지까지 규명하는 실험은 아니다. 이 설계가 검증하는 범위는 고정 분리기에 대한 입력 음향 변환의 기여다.

## 전체 구성

| 부분 | 비교 | 얻을 수 있는 결론 |
|---|---|---|
| 원인 대조 | 직접 지연만, 크기 변화, 위상 변화, 둘 다 | 어떤 입력 변환이 추가 분리 오류를 유발하는지 |
| 개입 대조 | 분리 전 EQ와 분리 후 역EQ, 같은 입력·정답 | 해당 변화를 완화하면 오류가 줄어드는지 |
| 원래 조건 확인 | 서로 다른 음원별 RIR에서 입력만 이용한 EQ | 단순화한 공통 RIR의 결과가 실제 프로젝트 설정에서도 이어지는지 |

세 부분을 한 가설의 진단·개입·적용 확인으로 묶는다. 여러 모델·학습 손실·가중치를 탐색하는 실험으로 확대하지 않는다.

## 고정할 자료와 분리기

원인 대조에는 기존 개발 10곡의 같은 중앙 30초와 기존 R4의 bass 위치 P3 RIR 하나를 사용한다. 이 RIR은 베이스 실패를 조사하기 위한 강한 잔향 사례로 사전에 지정한다. 다른 RIR을 결과에 맞춰 골라 바꾸지 않는다. 이 10곡은 이미 분석한 자료이므로 탐색적 원인 검증이다.

공통 RIR 대조에서는 네 음원에 모두 같은 RIR을 적용한다. 원래 실험은 음원마다 RIR이 다르므로, **공통 RIR에서도 문제가 재현되는지 먼저 확인**해야 한다. 재현되지 않으면 이 단순화로 원래 문제의 원인을 설명할 수 없다는 결과를 남긴다.

분리기는 HTDemucs 955717e8, FP32, shifts 0, segment 7초, overlap 0.25와 기존 공식 정규화를 고정한다. 데이터는 44.1 kHz stereo다. 모델 교체·앙상블·새 학습은 사용하지 않는다.

## 주파수 크기와 위상을 나누는 대조

RIR의 복소 주파수 응답을 H, 기록된 기하학적 직접 도달 지연을 d라고 한다. peak 시각으로 d를 다시 고르지 않는다.

```text
D(f) = exp(-j · 2π · f · d / fs)     직접 도달 지연
M(f) = |H(f)|                        주파수별 크기
A(f) = H(f) / [D(f) · M(f)]          직접 지연을 뺀 위상 성분
H(f) = D(f) · M(f) · A(f)
```

M이 수치적으로 0인 bin은 A=1로 정의하고 해당 bin 수·에너지와 재구성 오차를 보고한다. 0이 아닌 bin에서 |A|=1이어야 한다. 실수 파형의 공액 대칭과 DC·Nyquist 조건을 유지한다.

네 조건을 다음과 같이 만든다. 모든 stem에 같은 변환을 적용한 뒤 합산한다.

| 조건 | 적용 응답 | 고정되는 것과 바뀌는 것 |
|---|---|---|
| D | D | 기준. 도달 지연만 적용 |
| M | D×M | H와 같은 크기 응답, 직접 지연 외 위상은 제거 |
| A | D×A | 크기 응답은 1, H의 잔여 위상은 유지 |
| H | D×M×A | 전체 RIR 응답 |

크기 변화 조건 M도 시간영역에서는 앞뒤로 퍼지는 필터일 수 있다. A는 크기가 1인 위상 연산이지만 원래 방과 같은 에너지 감쇠 곡선을 갖는다고 보장되지 않는다. 따라서 이를 물리적인 초기·후기 잔향의 완전한 분리나 순수 RT60 조작으로 부르지 않는다. **주파수 크기와 위상 연산에 대한 통제 실험**으로 해석한다.

각 조건은 전체 혼합의 RMS를 D와 맞추는 공통 scalar 하나만 사용하고 그 값을 네 정답에도 똑같이 적용한다. stem마다 RMS를 따로 복원하지 않는다. 그래야 공통 필터 관계와 음원 간 상대 크기가 유지된다. 조건별 정답은 해당 변환을 적용한 stem이다. 공통 H의 재현은 베이스 E_H 중앙값 ≤−0.5 dB·CI 상한<0을 성능 악화의 기준으로 삼고, D에서 없던 gain<0.1 사례가 생기는지도 별도로 보고한다. 점수 악화만 재현되고 소실은 재현되지 않으면 둘을 구분한다.

## 신호 처리 때문에 생기는 가짜 차이 방지

M과 A의 진단 필터는 비인과적 성분이나 긴 응답을 가질 수 있다. 짧은 30초 FFT로 바로 처리해 끝이 앞으로 돌아오는 circular wrap을 실험 효과로 오인하지 않는다.

첫 구현은 30초 원 신호를 길이 2^22 샘플의 블록 중앙에 놓는다. 전체 길이는 약 95.11초이고 양쪽 guard는 약 32.55초다. 모든 조건에서 같은 블록 길이·위치와 같은 분리 구간 배치를 사용하고, 점수는 중앙의 같은 30초에서 계산한다. 분리 전과 분리 후의 필터 연산 중간에는 core만 잘라내지 않는다.

추론 전에 블록을 두 배로 늘린 DSP 계산과 비교해 중앙 신호의 상대 RMS 오차 ≤1e-4를 확인한다. H 재구성 상대오차 ≤1e-10, A 크기 오차 ≤1e-10, EQ 왕복 오차 ≤1e-6도 검사한다. 이 임계값은 수치 구현 점검의 제안값이다. 만족하지 않으면 해당 대조를 해석하지 않고 필터·경계 구현을 먼저 수정한다. 비교 길이 변경으로 모델의 chunk 위치까지 달라지는 효과를 보지 않도록 이 수렴 점검은 우선 DSP 신호에서 수행한다.

기존 30초 추론 cache는 guard와 모델 chunk 문맥이 다르므로 이 대조의 기준선으로 그대로 섞지 않는다. 모든 필요한 분리 출력은 같은 블록 조건으로 생성한다.

## 같은 정답에서 추가 분리 오류를 확인하는 기준

입력과 정답의 필터가 바뀌면 기존 오차의 점수도 달라질 수 있다. 각 조건은 절대 SI-SDR뿐 아니라 다음 순서 대조와 함께 본다.

```text
기준 출력 Z_D = F(직접 지연만 적용한 혼합)

실제 분리: 조건 필터 적용 → F
순서 대조: F의 기준 출력 Z_D → 조건의 나머지 필터 적용
```

예를 들어 M에서는 Z_D에 M을, H에서는 Z_D에 M×A를 적용한다. 공통 scalar의 비율도 보정한다. 두 출력 모두 같은 조건의 정답 stem으로 평가한다. 이 순서 대조는 정답 신호를 넣어 분리하는 방법은 아니지만, 알려진 합성 필터를 쓰는 진단이며 실제 보정 알고리즘으로 취급하지 않는다.

음원 k·곡 i·조건 c의 추가 손실 E를 다음처럼 기록한다.

```text
E(i,k,c) = SI-SDR[실제 조건 입력의 분리 출력, 조건 정답]
           − SI-SDR[기준 출력을 조건 필터로 변환한 출력, 같은 조건 정답]
```

D의 E는 0이다. M·A·H의 E가 음수이면 분리 전에 해당 변환이 들어간 경우가 분리 후 변환보다 더 나빴다는 뜻이다. 이는 해당 연산과 고정 분리기의 비가환성을 측정하는 대조이며, 분리 오류 전체를 원인별로 완전히 분해한 값은 아니다.

주 기전 비교는 베이스의 같은 곡 E_M−E_A다. E_H의 재현 여부, E_M·E_A 각각의 크기와 신뢰구간, E_H−E_M−E_A의 상호작용도 함께 보고한다. 중앙값끼리 빼거나 효과를 백분율 기여도로 바꾸지 않는다.

## 간단한 개입은 분리 전 EQ와 분리 후 역EQ

방법은 주파수별 양의 실수 gain Q 하나다. 좌우에 같은 Q를 적용하며 입력 위상은 유지한다.

```text
원래 잔향 혼합 x
   → Q로 크기 분포 조정
   → 고정 HTDemucs
   → 각 출력에 Q^-1 적용
   → 원래 잔향 정답 y_k로 평가

z'_k = Q^-1 { F_k(Q x) }
```

핵심은 마지막에 EQ를 되돌리는 것이다. **보정 후 출력도 원래의 wet stem과 비교한다.** 잔향을 제거한 정답으로 바꾸거나 출력의 저역을 키운 상태만 보고 개선이라고 하지 않는다. Q는 0이 아니므로 역연산이 존재한다. 분리기가 없는 Q^-1 Q 왕복이 항등임을 별도로 확인한다. 이 왕복 자체가 분리 성능을 개선할 수는 없다.

두 가지 Q의 역할을 구분한다.

| Q | 만드는 방법 | 해석 |
|---|---|---|
| 알려진 RIR의 Q | M의 역크기 응답을 1/3 octave로 평활화하고 보정 폭을 제한 | 원인 개입용 oracle. 실제 미지 공간에서 바로 쓸 수 있는 방법이 아님 |
| 입력만 사용하는 Q | 고정 기준 음악 스펙트럼과 현재 혼합의 크기 분포 차이를 평활화해 제한 보정 | 원래 음원별 RIR 조건에 적용할 간단한 후보 |

두 Q 모두 20~1000 Hz를 주 보정 대역으로 하고 ±6 dB 이내로 제한한다. 10~20 Hz와 1000~1500 Hz에서는 cosine 가중치로 log gain을 0 dB에 연결하고 나머지는 Q=1이다. 알려진 RIR의 M은 20~16000 Hz의 기하평균으로 나눠 전체 gain을 제거한 뒤 역크기를 계산한다. 세기와 대역폭을 결과에 맞춰 탐색하지 않는다. 이 값들은 기존 결과에서 최적화한 값이 아니라 이번 실험의 고정 제안값이다.

입력 기반 Q의 기준 스펙트럼은 준비된 학습 80곡의 추가 잔향 없는 혼합에서만 만든다. 각 곡의 좌우·시간 평균 power를 구하고 20~16000 Hz의 합으로 정규화한 뒤 주파수별 log power의 중앙값을 구한다. 기준 power/현재 입력 power 비율의 제곱근으로 gain을 계산한 뒤 같은 평활화·대역·상한을 적용한다. 스펙트럼 산출은 FFT 4096·hop 1024·periodic Hann으로 고정하고 30초 core만 사용한다. log power의 floor는 각 스펙트럼 최대 power의 1e-8로 사전 고정한다. 1/3 octave 폭에 bin이 없으면 가장 가까운 bin을 사용하고, 최종 log gain을 긴 FFT grid에 보간한다. 기준 통계를 쓰지만 분리기나 보정망의 가중치를 학습하지 않는다.

정답 stem, 원본 dry 혼합, 정답 베이스 활성 구간, 실제 RIR은 입력 기반 Q의 추정에 사용하지 않는다. 알려진 RIR의 Q가 성공하고 입력 기반 Q가 실패하면 진단과 실용 방법의 차이를 그대로 보고한다.

## EQ 대조 조건

공통 RIR H 입력과 직접 지연만의 D 입력 각각에서 다음을 비교한다. H에서 정한 Q를 해당 곡의 D에도 그대로 적용해 일반적인 EQ 효과와 잔향 조건의 추가 효과를 나눈다.

| 비교 | 목적 |
|---|---|
| 기존 출력 F(x) | 기준 |
| Q^-1 F(Qx) | 제안한 개입 |
| g^-1 F(gx) | Q 적용 입력과 전체 RMS가 같은 scalar gain 대조 |
| Q^-1 Q F(x) | EQ 왕복·잘라내기 오차 대조. 추가 신경망 추론 없음 |

잔향 특이적 효과는 곡별로 `[H에서의 EQ 개선] − [D에서 같은 Q의 EQ 개선]`을 먼저 계산한 뒤 집계한다. 양수면 같은 EQ가 단순 지연 입력보다 전체 RIR 입력에서 더 도움이 됐다는 뜻이다. 값이 0이면 일반적인 모델 입력 조정 효과일 수 있다.

## 원래 음원별 RIR 조건에서 적용 확인

공통 RIR은 원인 대조를 위해 단순화한 조건이다. 다음 확인에는 현재 준비된 validation 10곡에 기존 R4의 음원별 RIR을 적용하고 기존 stem RMS 복원 규칙을 유지한다. 입력 기반 Q만 사용한다. 원래 입력과 같은 정답에서 무보정·EQ 개입·scalar 대조를 비교한다. 추가 잔향 없는 혼합에서는 그 입력 자체로 Q를 다시 추정한다. 여기서는 동일한 Q 추정 알고리즘을 검증하며, 공통 RIR의 인과 대조에서 같은 Q 수치를 H와 D에 적용한 것과 구분한다.

공통 RIR의 oracle 결과를 이 원래 조건의 해결 성능으로 대신하지 않는다. 두 집합은 다른 곡·목적이므로 수치도 분리한다. validation 10곡은 이미 학습 준비 점검에 사용됐으므로 완전 미관측 최종 평가라고 부르지 않는다. 학습 실험의 confirmation 10곡과 기존 evaluation claim은 사용하거나 변경하지 않는다.

## 관측할 값과 판정

기존 함수로 SI-SDR·SI-SIR·SI-SAR·target gain을 계산한다. 베이스 소실은 기존 target gain<0.1로 유지하며 실제 출력 RMS도 따로 본다. 베이스와 일치하는 성분의 bass·other 출력 투영 계수를 함께 기록한다. 투영 계수는 에너지 이동 비율로 해석하지 않는다.

각 곡의 모든 조건을 묶어 10,000회 bootstrap한다. 주요 수치는 같은 곡의 대응 차이 중앙값과 95% CI다. 10곡이므로 탐색적이며 통계적 비유의성을 무효과의 증거로 쓰지 않는다.

아래 수치는 실행 전에 고정할 프로젝트 판단 기준의 제안이다.

| 결과 | 판단 |
|---|---|
| 공통 H에서 추가 손실과 소실이 재현되지 않음 | 공통 RIR 단순화로 원래 문제를 설명하지 못함. 음원별 RIR 차이 등 남은 요인을 기록 |
| E_M이 −0.5 dB 이하이고 CI 상한<0, E_M−E_A의 CI 상한<0 | 이 통제 조건에서 크기 변화의 기여와 상대적 영향이 지지됨 |
| E_A도 음수이고 CI가 0 아래 | 위상·시간 구조도 기여. 착색만이 원인이라고 하지 않음 |
| E_M·E_A는 작고 E_H만 크게 음수 | 결합·상호작용 가능성. 한 요인의 단독 설명을 보류 |
| 같은 H 정답에서 EQ 개선 ≥+0.5 dB·CI 하한>0, scalar 대비 차이 CI 하한>0, H−D 개선 차이 CI 하한>0 | 주파수 크기 보정이라는 개입의 잔향 조건 효과를 지지 |
| oracle EQ만 성공하고 원래 조건의 입력 기반 EQ는 실패 | 원인 기여의 단서와 실용 해결의 실패를 구분 |
| 입력 기반 EQ가 원래 조건에서도 베이스 ≥+0.5 dB·CI 하한>0, 나머지 각 음원의 변화 중앙값 ≥−0.2 dB, 추가 잔향 없는 베이스 변화 중앙값 ≥−0.2 dB, 새 베이스 소실 없음 | 단순 보정 후보로 후속 검증할 근거. 비열등성의 통계적 확정이나 현재 자료 밖의 성공은 미확정 |
| EQ는 좋아지지만 원인 대조가 가설을 지지하지 않음 | 성능 조정 효과만 관찰. 원인이 증명됐다고 하지 않음 |

다른 음원의 손상은 각각 보고하고, 추가 잔향 없는 조건에서의 악화도 포함한다. 소실 개선은 분모·회복·새 소실 수를 함께 적는다. 최악 사례 몇 개만 좋아진 결과를 전체 효과로 제시하지 않는다. 원래 대역 정보가 거의 없는 깊은 notch를 EQ로 복원했다고 주장하지 않는다.

## 규모와 수행 순서

원인 대조 4조건×10곡은 40회다. 공통 RIR의 EQ·scalar 개입을 H와 D에 적용하면 40회가 추가돼 핵심 단계는 총 80회다. 순서 대조와 DSP 왕복은 기존 출력을 변환하므로 추가 신경망 추론이 없다.

원래 조건의 적용 확인은 wet/dry 각각 무보정·EQ·scalar의 6조건×10곡, 최대 60회다. 전체 상한은 140회다. guard 포함 95.11초 입력과 과거 HTDemucs warm RTF 0.063을 단순 곱하면 순수 forward 약 14분이다. CPU FFT·파일·지표·로딩은 별도이며 실제 전체 시간은 한 곡 pilot으로 먼저 측정한다. 신경망 학습은 없다.

1. 곡·RIR·Q 규칙·판정 기준을 manifest로 고정한다.
2. 필터 곱·크기·경계·EQ 왕복부터 검사한다.
3. 한 곡 pilot으로 설정과 시간만 확인한다. 점수에 맞춰 Q를 다시 고르지 않는다.
4. 원인 대조와 공통 RIR 개입을 실행한다.
5. 입력 기반 Q의 원래 조건 적용 확인을 별도 표로 집계한다.
6. 원인 지지 여부·단순 개입 효과·실용 적용 여부를 세 문장으로 분리해 결론을 쓴다.

새 결과는 별도 `cause-eq-v1` 경로에 보존하고 기존 학습 readiness·checkpoint·data cache를 수정하지 않는다. 이 문서 작성 시점에는 새 분리 추론·EQ 성능 실험을 실행하지 않았다.

설계식의 산술 점검만 수행했다. 실제 R4/P3 RIR의 131072점 주파수 응답에서 H=D×M×A의 상대 재구성 오차는 1.99e-16, A의 단위 크기 최대오차는 6.66e-16이었다. 별도의 간이 유계 Q에서 EQ 왕복 상대 RMS 오차는 8.15e-16이었다. 이는 식의 구현 가능성 점검이며, 위에서 정한 Q 추정 규칙·95초 블록 경계·분리 성능이 검증됐다는 뜻은 아니다.

## 참고 범위

[Jungmann 외 2015의 저자 기관 초록](https://research.uni-luebeck.de/en/publications/joint-time-and-frequency-domain-reshaping-of-room-impulse-respons/)은 시간영역만 최적화한 잔향 보정이 spectral distortion을 만들 수 있음을 설명하고 두 영역의 공동 제어를 다룬다. 이번에는 시간과 크기 변화가 함께 바뀌는 대조의 혼동을 피할 근거로 사용한다. 그 논문의 성능을 현재 HTDemucs EQ의 예상값으로 사용하지 않는다.

[Traer와 McDermott 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5137703/)은 IR 특성을 조작해 인간의 음원·환경 지각을 조사했다. 원인 후보를 통제된 신호 변환으로 확인하는 실험 방식의 참고이며 HTDemucs에서 같은 기전이 작동함을 입증하는 근거는 아니다.
