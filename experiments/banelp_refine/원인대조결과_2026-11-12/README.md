# 원인 대조와 전후 EQ 실험 결과

상태: 완료

원인 대조 10/10곡, 적용 확인 10/10곡을 집계했다. 공통 RIR의 추가 악화는 재현됐지만 크기 변화가 위상 변화보다 주된 원인이라는 사전 기준은 통과하지 못했다. 위상 조건도 추가 손실을 보여 주파수 착색만으로 설명할 수 없다. 알려진 RIR을 사용하는 EQ 개입은 공통 잔향 조건의 사전 개선 기준을 통과했다. 이는 oracle 개입이다. 입력만 이용한 EQ는 원래 음원별 RIR 조건의 실용 후보 기준을 통과하지 못했다. 현재 방법이 원래 문제를 해결했다고 말하지 않는다.
